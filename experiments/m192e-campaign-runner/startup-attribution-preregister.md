including all clock, interval, coverage and acceptance expressions. Original,
changed and restored digests plus both count dictionaries are retained. This
is a source identity assertion; independent source review must still compare
the changes rather than treating an author's digest as verification.

exit, native result where applicable, error and phase name. Actual Popen argv,

and original process-counter creation records. Expected startup phase count/
order must be exercised exactly. Eight native/host/file brackets plus one
injected-delay row at most fit the declared twelve-row ceiling. Off retains
an explicit empty instrumentation record.

Injection is a separate named row. It is not charged to an invented native
latency: the Popen native bracket starts after the pre-Popen injected delay;

Thread CPU versus QPC can distinguish blocked/scheduled time from active

Imports preserve the commissioned sampler/harness environment, including
