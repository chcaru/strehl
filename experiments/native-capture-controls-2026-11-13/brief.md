# Capture controls and admission

Add a private phone pairing QR, coalesced absolute focus scrubbing, native preview
focus peaking, an unobstructed preview, and selectable single/four-shot capture.
Correct planned duration and disk estimates when the selected mode changes.
Refuse a stack that cannot fit before any focus movement or shutter release,
including requests made through the phone API. Recheck the pinned destination
during capture. Compression savings must not be assumed for admission.

Reproduce and fix native dropdown growth under pointer movement. Exercise the
actual egui layout and render paths, not only static screenshots. Test flat and
edge preview controls for the focus aid; make no RAW quality claim from peaking.
Qualify both camera modes on the idle A7CR, preserve its focus marks and settings,
and keep originals, credentials, unrelated changes and background receiving.

Use the local desktop control interface, isolated test destinations, simulator
and short hardware runs. Package the verified build with source and rebuild
instructions. Record commands, build identity, outcomes and remaining limits.
