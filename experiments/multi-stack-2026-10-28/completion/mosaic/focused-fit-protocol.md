# Focus-matched FIT commissioning

This is development on the already inspected marigold2/3 scene. Its existing
held islands have informed the hypothesis and are retained as a fixed diagnostic
comparison, not fresh final generalization. No new held islands are consumed.

The completed focus-island arm supplies the exact source census, two independently
aligned pass maps, guide hashes, initial FIT-only seed and frozen role plan.
The current production binding and saved measured geometry must reload exactly.
The initial FIT artifact, seed and all attempted ancestor footprints must still
match the frozen plan. Missing or different dependencies refuse the replay.

Before any new native read, freeze this nomination:

1. Use native-quad anchors at64+128n in each axis, within the reference source.
   Around each, inspect the existing4quad guide lattice within L-infinity48quad.
   Rank by squared displacement to the anchor, then y and x.
2. Require covered and usable-focus flags in both guides at the candidate and
   the frozen initial-FIT-similarity prediction. Use the existing nearest moving
   guide lookup. Keep first ranked original A and up to three distinct originals
   B from the corresponding guide lists; no residual, NCC or intensity ranking.
3. A candidate pair must reserve the production coarse-NCC footprint in both
   source/pass gauges wholly in FIT outside the existing held islands. Use the
   same conservative120native-quad window times the inverse source-placement
   L1 scale used by the production grid nominator. Exact runtime observers still
   check every attempted original tap, reciprocal query and filter halo; any
   later escape refuses the attempt. This precheck is not an acceptance test.
4. Choose the first geometrically eligible centre for each anchor and retain its
   eligible source pairs. Keep all failed geometric candidates and unavailable
   anchors. There is no retry after a native score. Limit to at most512 nominal
   anchors and1536 source pairs; larger geometry refuses rather than truncating
   to a spatially biased prefix.
5. Mark these as generated grid nominations. They must execute the production
   coarse original-image NCC search before unchanged native reciprocal fitting.
   They are not reciprocal descriptor matches and do not receive that label.
6. Save all source IDs, nominal/selected coordinates, masks, ordinal/width,
   ranking, reservations and the complete nomination hash before native reads.

Predeclared geometry arms retain every attempted/refused receipt:

| Arm | FIT input | Held input |

| focused only | New frozen focus-matched native receipts | Same prior held receipts |

All arms use the same production same-site/support selection, global geometry,
mesh fit,0.5quad native/reciprocal/held bars and measured-hull qualification.
There is no removal of inconvenient native measurements based on fitted residual.
If the focused arm has insufficient independent FIT evidence, report refusal.
Native nomination counts and fit error are not output-quality evidence.

Controls exercise nearest/tied selection, frozen source ranks, absent focus,
wrong source identity, existing held reservations and signal-independent
nomination. Existing original-pixel role/halo/reciprocal poison controls remain
part of the compiled harness. Memory is3GiB work plus512MiB cached CFA, at most
four workers, cached originals only. Root schedules the real run after review.

Before final qualification, a new deterministic validation plan must be reserved
without consulting its native measurements. A future denser held plan must also
report physical hull capacity and remaining FIT support before reads; it cannot
silently replace or erase these known-scene diagnostic results.
