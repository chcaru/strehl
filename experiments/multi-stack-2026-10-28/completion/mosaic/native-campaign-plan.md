## Frozen consumer contract

`session-mosaic-consumer.rs` is a child of `session_consumer`, dispatched only for
Mosaic. It independently aligns every explicit pass using direct measured edges,
then embeds each pass map at full-session source indices. This keeps acquisition
order, continuation segments and the per-pass gauge. A one-pass view is never
mistaken for another pass merely because it came from another directory.

The shared focus evidence supplies ordinal, width, coverage and ambiguity. It is
not physical depth. Bounded single-original CFA guides propose scale-space
descriptors; their actual source witnesses map into the per-pass gauge. The
focus-composite diagnostic supplies source nominations and focus coordinates,
not descriptor intensities. An unverified transform can nominate distributed
original-image NCC searches. At least eight accepted native fit observations are
required for a measured pass edge; spatial heldouts qualify the jointly fitted mesh.
Only a measured connected pass graph can establish the extended canvas. The
global reference fixes coordinates and the development color basis; stitching
does not permit a primary appearance source.

The renderer uses globally phased work tiles with an explicit eight-times-phase
dependency halo. Each pass consumes original CFA with the composed map and
optical correction at physical CFA sites. The mapped sampler delegates its
unchanged fixed-mesh entry to the new mapping closure entry. Four deterministic
known-noise realizations measure each actual gather/pyramid operator over a
canonical full mosaic domain, once per placed source before output allocation.
Those gains are reused across all tiles, so changing tile size cannot change
their spatial-average estimator. Batches use at most four jobs and at most
`max(1, workers / 4)`, additionally limited by the explicit probe-phase budget.
A minimum full-domain probe that cannot fit is refused rather than silently
changing the domain. Bands with
no supported coefficient retain zero observation counts, not identity beta.
This is an operator probe, not another sensor-noise model.

Within a view, all positive fitted cells retain one continuous map. SingleView
cells are regularized extrapolation, not independently validated overlap.
Qualification controls cross-view blending without switching coordinate systems.
Failed local cells remain transparent through complete operator support. The
original global seed remains a bound comparison arm; substituting it locally
would require a displacement/derivative transition certificate or an explicit
alpha gap. The consumer does not make that discontinuous substitution.

Existing noise-gated `SessionMerge` reconstructs each pass in the tile. Only
qualified overlap with compatible reconstructed CFA values enters a feathered
mean. Conflicting or unqualified overlap uses the view farthest from its original
boundary, with declared order breaking exact ties. It is marked **unmerged**, not
silently advertised as a seamless join. A later third-view disagreement restores
the retained original owner values, rather than an earlier mean. Strict complete
multiscale support remains alpha-invalid where unavailable; no new boundary
selector/estimator is introduced before this path is validated.

Output is one full union photograph, RGB/sensor masters, full-resolution coverage,
quad-resolution view-owner and join-confidence maps, bound geometry/measurement
receipts, per-pass alignment/focus receipts, and uniform completion/source files.
The writer excludes uncovered holes from exposure/tone percentiles and applies
unassociated alpha with the complete demosaic support mask. Zero master storage
outside the mandatory coverage sidecar is not a black observation. The separate
sensor master is streamed Gray32Float RGGB with signed black-subtracted native
DN and an explicit schema, coordinate origin, nominal gain basis and coverage
reference. It is a single merged image, not an aligned source volume. Completion
binds whole-file SHA256 for photograph, RGB master, CFA master, final eroded
coverage, owner and join-status files before the final source census/hash check.

The memory plan separately reserves original CFA cache, source decode/copy,
retained sparse geometry, the largest tile's sampler/probe/merge/compositor work,
and 256 bytes per output quad for output/development/alpha work. It tests the
whole canvas first, then descending 8192/4096/2048/etc core sides, choosing the
largest fitting plan. It refuses an impossible output/tile budget before probes
or output allocation. The canonical probe phase is separately reserved and its
scratch is dropped before output allocation. A 33-million-quad canvas cap keeps
classic TIFF products below format offsets even if more RAM is available.

## Acceptance and foils

Run flat controls before any sharpness measurement. The new production-path
synthetic control passes original CFA through the mapped sampler, measured noise
probe, existing multiscale focus consumer and compositor. It requires a valid
union wider than one input, a positive qualified join, explicit uncovered pixels,
and whole-canvas versus tiled equivalence. Unqualified geometry must remove the
blend while retaining true single-view coverage. An unrelated/periodic matcher,
native flat patch, bad heldout cell and third-view radiometric disagreement each
exercise a different refusal mechanism. These are code controls, not photographic
quality evidence.

For real geometry retain all candidate/native/heldout IDs and report per-pass
connectedness, pass cycle rank, observed reciprocal loops, positive Jacobians,
qualified cell count/area and heldout placement in quad and sensor pixels. Use
heldout spatial blocks and separate focused source neighborhoods. Evaluate native
placement directly; successful final fusion cannot establish better geometry.

Compare the fitted local mesh with its measured global-similarity-only placement
and a one-shift-per-frame foil. Also compare stack-then-stitch through the same
canvas/display transform. These arms must retain explicit provenance and must
not reuse a local mesh's qualification to certify the simpler model. A failed
foil is useful only alongside a positive delivered mosaic.

Inspect each complete output at the same display recipe plus native-sized seam,
petal/depth-edge and single-view witnesses (record origin/size). Check alpha and
coverage against originals, image values on both sides of ownership changes,
disocclusions and unmerged masks. Commission the viewer before claiming absence
of resampling artifacts. Independent review must challenge the correspondence
finder, spatial holdout split, focus-coordinate interpretation, reference,
comparison arms and actual useful extended field of view.

The lane is complete only after a useful complete original-CFA mosaic, core/CLI/
desktop workflow, optimization and ordinary-stack non-regression are measured.
Sparse commissioning, a successful refusal or a documented limitation is not
completion of the user's mosaic outcome.
