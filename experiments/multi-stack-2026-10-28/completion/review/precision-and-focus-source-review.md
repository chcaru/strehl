## Findings before implementation

1. **VERIFIED source defect: censored competing mode.** A broad Gaussian primary (65 ordinals, center 20, width 4, amplitude 12, floor 0.54) plus a narrow amplitude 10 mode at 48 fooled the old far-sample/three-width exclusion: the strongest far sample was a primary shoulder and was discarded, hiding the real secondary mode. The replacement records actual local maxima, plateaus, boundaries and unresolved significant overflow. Width remains a local shape descriptor, never confidence. Missing focus-footprint samples cannot exclude an unseen mode; they now refuse usable evidence while retaining the observed fit and support count.
2. **VERIFIED source defect: two-pass mismatch.** Equal source IDs alone did not bind regularized responses and validity between passes. The root added canonical SHA256 binding; this reviewer batched the identical byte sequence in 64 KiB chunks and added an exact legacy-byte comparison. Ordered folds and finite posterior-domain checks protect the new streaming census and old entropy arithmetic.
3. **VERIFIED source defect: guide masks replaced source masks.** `predict_precision` reused `gaussian_support`, while `SessionMerge::add_source` still read that mask to prefer uncensored source hull values. A full guide could relabel clipped source data; a guide hole could relabel clean data. The root added separate guide scratch immediately; this reviewer owns adversarial final-hull controls and reservation verification.
4. **VERIFIED API gap: prediction metadata unbound.** `predict_precision` accepted a different NoiseModel, photometric gain or band-gain list from source preparation. The new path must validate identical resolved metadata, using the one injected source model. Changed gain/noise/beta and invalid noise must refuse before precision becomes ready.
5. **VERIFIED API gap: identity narrowing and partial mutation.** SourceKey acquisition is u64; precision originally narrowed it to u32 after group state mutation. Identity must remain u64. Guide/source membership checks must complete before inserting IDs; rejected duplicate membership must not contaminate subsequent valid folds.
6. **VERIFIED evidence gap: contribution statistics discarded.** The helper retained effective-source count, primary fraction and dominant acquisition, but final fusion discarded them. Counts of accepted means cannot establish delivered photon weights. Add bounded per-band attribution for the actual weighted or plain fallback normalization. Saturated display fallback must remain explicitly non-statistical. These are band coefficients before pyramid collapse and hull clamping, not cross-band final-pixel variance.

## Estimator contract and causal controls

A common nonnegative scalar precision across all four planes avoids channel-specific source mixtures. With source coefficient x_i, frozen prediction vhat_i, actual modeled source variance v_i and eligibility e_i, use q_i=e_i/vhat_i and a_i=q_i/sum(q); the fixed-weight model variance is sum(a_i^2 v_i). A zero predicted variance has an explicit zero-variance limit; it must not invent a noise floor. Keep eligible-input and positive-weight counts distinct. Effective independent-source count is 1/sum(a_i^2), not the number of files. Duplicate photon content cannot count as independent.

The unchanged equal-Welford residual gate may define a shared compatibility mask; it must not be relabeled a weighted-residual test. The candidate and its group energy then change together under precision. A causal evaluation needs both a fixed-eligibility/weight observer and the full adaptive path to separate coefficient averaging from changed focus weights. Same-sample variance prediction has a known downward-bias foil. A third original guide excluded from every group member removes direct same-photon weighting dependence within that group, but nearest logscale does not establish matching focus, visibility or local signal. Guide prediction must be evaluated in each source's signal domain and over the actual operator footprint. A source-position predictor or conservative local signal envelope is needed at strong edges; an output-center guide assumes locally constant signal.

Guide reuse in other groups and focus/registration admission based on scored photons make final uncertainty conditional and approximate. Hold geometry, group membership, source support and display fixed for equal-versus-precision controls. Measure temporal error on source-qualified flat regions with disjoint guide/measurement photons, preserving a real texture-transfer sentinel. Compare against both constituent controls; candidate-minus-a-constituent is correlated and is not independent truth. Exercise clipped/color-mismatched/defocused guide controls, incomplete guide fallback, zero noise, gain-squared propagation, metadata mismatch, u64 IDs, diagnostics-on/off pixel identity and peak-memory reservation before a complete real campaign.

## Remaining reviewer challenges

The local-mode census is conservative: a broad noisy peak can contain shallow local maxima whose heights exceed the global-floor ratio. The current competing-mode flag does not measure valley depth or calibrated multilayer probability. The real focus-map review must report mode/refusal coverage and challenge shallow-mode false refusals before interpreting them physically. A later valley/noise distinction needs its own positive and negative controls.

Precision predictions still use the inherited spatial beta approximation and focus-dependent guide assumptions. Added contribution maps improve observability, not sensor calibration or independence. Full held-out signal/noise controls and complete photographs remain necessary to realize the requested benefit.
