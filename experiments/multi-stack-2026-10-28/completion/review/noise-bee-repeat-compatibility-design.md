## Decision and finite power

The fixed first operating point is a signal-disagreement cost upper envelope no more than0.5of predicted equal-average noise benefit, plus a5% **amplitude** interval in both signed transfer directions for each AC(mid/high) band. Low carries raw-gain brightness consistency; it cannot certify texture. Both AC signal-energy lower envelopes must be positive. A failed upper admission envelope means UNKNOWN unless a lower envelope establishes incompatibility. Every declared patch/color/band remains visible. At least64disjoint points per patch are required;1024is the hard maximum. No threshold has been chosen from a real output improvement.

For an observation vector `d=s+epsilon`, define `Q=||d||²`, `L=||s||²`, `T=tr(C)`, `A=tr(C²)`, and a conservative spectral bound `v>=||C||`. For independent Gaussian point errors with known fixed covariance, the centered Gaussian quadratic-form moment generating function gives tails bounded by `2*sqrt(t*(A+2*v*L))` below and that quantity plus `2*v*t` above. The code inverts these inequalities for an interval onL; a negative inversion discriminant is UNKNOWN, not a silently clamped success. The derivation is specific to the Gaussian commissioning model. The general quadratic-form literature provides related concentration tools ([Hsu, Kakade and Zhang, 2012](https://www.cs.columbia.edu/~djhsu/papers/quadratic-ecp.pdf)); the implemented noncentral inversion is derived here, not copied implementation.

For cross signal, use the polarization identity `S1·S2=(||S1+S2||²-||S1-S2||²)/4`, retaining an interval from both quadratic envelopes. Divide this signed cross interval by each positive source signal-energy interval to obtain both amplitude-transfer directions. Opposite texture and phase/shift mismatch cannot pass merely by equal energy. The joint3band disagreement also uses all covariance entries, with the row-sum spectral bound. `t=log(100)` is a frozen commissioning constant, not a literal real1%error guarantee: guide error, fitted geometry, calibration, quantization and acquisition selection violate the simple conditional model.
