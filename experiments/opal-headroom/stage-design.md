## Actual consumer and falsification

Use only the new complete155-source baseline cache, crop[60,40,3396,2264],
reference77. The actual write_merged helper owns WB, black subtraction, exposure,
normalization, full mosaic construction and the actual resolved tone. No rounded
log values are reconstituted. The observer calls the actual full-context MHC
row function and real Render::clip_highlights, highlight::desaturate,
Render::develop, private Tone::gain, existing shoulder_rgb and private gamut_map.
It scans every pixel with one scratch row, retaining only two384px regions.

Every counted stage chain must reproduce the actual Current and Shoulder pixel
helpers exactly. Streaming hashes of those complete observed RGB16 sequences
must match both prior factorial masters. Thus counts cannot silently come from
an alternate colour pipeline. The Current observer on/off actual complete TIFFs
must be byte-identical, and resolved development must agree. Frozen region RGB16
arrays are compared with both masters; cache/source bytes remain bound.

Whole-image and per-target counts distinguish: per-channel/any pin predicate;
actual clip change; actual rolloff change; negative MHC components; nonpositive
developed luminance; post-tone channel overflow, luminance>=1 and negatives;
shoulder change; current/shoulder gamut change and exact white outputs. These
are event counts, never quality scores or original sensor clipping estimates.
The frozen target arrays store actual MHC, post-clip, post-rolloff,
post-develop, post-tone, post-shoulder, current gamut and shoulder gamut f32 RGB.

For EVERY pinned pixel inside either target, save its actual normalized5x5
merged CFA mosaic neighbourhood and absolute output-native coordinates. Record
whether all25 values are strictly below their OWN channel ceilings. A pin with
this property is generated by interpolation from that merged stencil. It does
not prove the original RAWs were unclipped, or that removing pin protection
would improve the photograph. The5x5 full square is a conservative superset of
all MHC taps; its checker uses absolute CFA parity.

Three commissioning tests must execute. One separately exercises below-knee null,
pin-only change, rolloff-without-pin and display saturation from unpinned input;
it checks counters were actually live. The other supplies real MHC with all
CFA samples<1 yet creates an interpolated green>1, contrasted with a constant
flat below-ceiling negative. Root should challenge the choices as well as rerun
them: a counted pin is not synonymous with changed output, a white display
pixel is not synonymous with RAW saturation, and one positive synthetic MHC
case does not establish opal's cause.

The third independently authored control distinguishes an equality pin with no
clip change from one-ULP-below/above cases. It tests every RGGB phase with
unequal red/green/blue ceilings, at half, exactly at, and one ULP below its own
ceiling. The whole-module test filter includes these three controls plus the
one ignored real-cache test; controls must report3 passed,0 failed,1 ignored.

The support implication is one-sided: all25 below their own nominal container
ceilings establishes that this post-MHC crossing was absent in those merged
inputs. A failed support condition is inconclusive about cause. It does not
establish original RAW clipping or an automatically bad output pixel. See the
independent-stage-review.md qualification.

## Causal branch after the observation

If both frozen targets have no pin/clip changes, stop the opal pin branch.
If pin is active but clip changes no values, the pin path did not remove those
values. If clip removes distinctions at the complained-of location, first use
the saved actual5x5 support to determine whether interpolation created the
threshold crossing. Do not immediately bypass the pin protection. Only if a
remaining question specifically concerns original clipping should the next
bounded source-contribution trace gather all155 sources' actual taps and
contributing weights at that predeclared location; three old originals or a
raw argmax cannot answer it.

If post-tone distinctions survive until gamut, the cached trace locates display
loss. Compare actual current and the already executed fixed shoulder at the
same locations; do not retune the shoulder. If all four full rendering arms
fail visually and the relevant distinctions are already absent in the merged
radiance, return to root's actual source-contribution investigation. No display
curve can establish recovery of information already lost upstream.
