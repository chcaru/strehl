# M194 source-path commissioning, before implementation

2026-09-07. Allocated in AGENTS before dispatch. Prior-art audit:
`experiments/review-production-truth/audit.md`; all named prior refusals remain.
This commission establishes a decoded-CFA input seam into the existing Pyramid
product path, not optics fidelity, calibration, registration coverage, detail
quality, or SOTA. No M25 renderer or frozen experiment is changed.

Before code, roadmap_audit independently requested non-square distinct-CFA
fixtures, off-axis texture, live frame/warp/output mutations, unchanged-endpoint
curvature controls, nonzero crop origin, actual TIFF decoding, error propagation,
refused-frame behavior, and confidence/debug rereads with nonexistent source
paths. Its controls will live separately from the author's child module.

Falsifiers registered before implementation:

1. The default RAW wrapper must call the same prepared merge body as the
   synthetic source. Any copied arithmetic fold/writer is a failure. Preserve
   canonical chunk grouping, operation order, existing gather/floor logic,
   four-plane collapse, confidence consumers, and output arithmetic.
2. Small non-square, multi-frame u16 CFA inputs must produce real TIFFs through
   the current writer. Distinct channel sites, texture, and genuinely curved
   per-frame placements must occur, and their occurrence is asserted.
3. A large change to an upstream frame, an interior warp with unchanged
   endpoints, and a changed output setting must alter delivered pixels or the
   declared output dimensions. An inert source delegate must remain byte exact.
4. Confidence on/off must produce identical main TIFF bytes; source decode
   counters must prove every expected reread. No disk fallback is admissible
   for synthetic sources with impossible paths. Debug confidence uses the same
   source as normal confidence and the fold.
5. Decode failures, bad source count, and all-refused placements must fail
   loudly. A partially refused map must omit the refused frame consistently
   from fold and confidence. Valid controls must succeed.
6. Crop must act at the existing compact domain and correct full-plane origin;
   demosaic and binned output must have the expected actual dimensions. Exact
   output pixels and TIFF metadata are observed, not inferred from file size.
7. Native RAW byte-lineage checks use only authorized existing development
   freezes, after inspecting the harness's paths and environmental isolation.
   New source must visibly compile in a unique target directory. A failure
   stops an unchanged-output claim; historical references are preserved.

Initial synthetic input generation is a path stimulus, not a physical focus
renderer: no fabricated defocus/occlusion validation. Independent scene/noise
rendering and a fully commissioned quality instrument are later work. No metric
or threshold is tuned on a candidate admission change in this milestone.
