## Two execution changes only

1. Parallelize independent output rows/paired low-high rows within each 1-D
   analysis and synthesis stage using the existing Rayon pool. Preserve tap
   order and f32 arithmetic within each output. Keep stages, source order,
   four CFA planes and16 noise members sequential. Do not run multiple
   full-source workspaces concurrently. No new GPU/precision/FFT backend.
2. Replace unnormalized weighted numerators with a per-coefficient running
   maximum weight scale. Rescale the existing numerator and denominator when
   a larger weight arrives, then add the new weight divided by that scale.
   One scale and denominator serve all four complex CFA coefficients. Keep
   the actual original weight, gate, floor and exponent. Mean fallback and
   terminal DC remain unchanged. This changes floating association, not the
   mathematical relative weights. It must survive a finite-weight product
   adversary that overflows the old f32 numerator.
