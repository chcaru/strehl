# Independent Device256 native results

VERIFIED from the seven saved native executions, their commands, logs, profiles and output receipts; no reviewer render, RAW decode or additional numerical campaign. The fixed Device256 implementation preserves every complete RGB16 TIFF and has a substantial measured whole-process speed benefit on the admitted 22-frame 109MSDCF subset. This is a speed/preservation result, not a quality improvement or SOTA claim.

DERIVED from these recorded whole-process times: per-mode minima give a 27.0553% wall reduction; medians give 26.6167%. Forward/reverse comparisons give 27.1593%/26.0734%. The least favourable pairing still gives 26.0734%, while CPU endpoint drift is only 0.016 seconds and GPU spread 0.110 seconds. The observed benefit therefore survives direction and extremum choice in this allocation. Two samples per mode do not establish a population confidence interval. Child CPU minima fall 57.4672%; that is CPU consumption, not electrical energy. GPU job commit is about 0.52–0.55 GB higher; these figures are neither VRAM usage nor resident memory.

Re-choosing phase attribution rather than reporting gather alone: current CPU gather+probe is 7.1115901/7.1030356 seconds, versus GPU 4.1081114/4.2084311. Both gather and probe improve. Decode-validation is 1.1937255/1.1782715 seconds on CPU and 1.1708848/1.1590836 on GPU, a cross-arm difference of only 0.0074–0.0346 seconds; it cannot explain the roughly three-second whole-process gain. Collapse/write stays 0.320–0.325 seconds. The combined gather/probe reduction accounts for nearly all the gain, while startup, packing, transfers, waits and writer remain included in whole-process timing. Profile phases are wall intervals, not separate CPU or GPU kernel timings. Whole-host busy fractions include the measured job and cannot independently identify external contention.

Source/route scope: Device256 makes f64 coordinate plans on the GPU; the protected f32 image shader is unchanged. The logging-on native record carries the same original/submitted coordinate hashes (`95eb96b6...` / `232804bc...`) and protected gather hashes (`41658a89...` / `a7dce210...`) as the fixed controls. The unsafe coefficient fallback remains available but was used by none of these 136 RGB/green calls.
