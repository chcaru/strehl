# Independent source review before execution

Reviewed `image-out-bridge.rs`, `merge-replay.rs`, `run.py`, and the actual current developer/color/pin/rolloff implementation. Independent controls and plan are separately authored. No build, controls or photograph was executed by this reviewer.

The explicit Current arm calls the actual production developer. Candidate arithmetic keeps the current pinned-sensor protection and current camera matrix, changes only the named desaturation factor and/or fixed0.75 exponential luminance shoulder, then uses the same tone/exposure, gamut map, transfer and S-curve. The shoulder uses one RGB gain. Source inspection confirms declared placement and factor separation; it is not a numerical pass or photographic benefit.

The test-only full-writer override is serialized and uses `try_lock`, so an attempted concurrent/nested invocation refuses. The current observer path literally bypasses pixel modification. Root integrated hooks only under the named diagnostic feature/test configuration. The four independent pixel controls must run serially because the full-writer mode is process global. Their low-level noisy flat is invariant, not a calibrated noise experiment; no high-highlight noise guarantee is made relative to a current hard white plateau.

The full replay requires `phase=full`, so a three-source cost cache cannot masquerade as a complete photograph. It hashes the cached planes, verifies the current observer off/on whole-file hash, then compares every current RGB16 sample and ICC byte with the retained master before creating candidate arms. Every factor shares exactly the same resolved tone, exposure, matrix, ceiling and sensor-top metadata; dimensions and ICC stay exact. Memory-plane hashes and original-master/cache bindings are checked afterwards. The current writer is reused for MHC/output, rather than replacing it with an independent display approximation.

The runner checks source and executable bindings against a shared build with a fresh `Compiling strehl-cli` line, runs exactly four serial control tests, and validates successful bounded process completion. Replay is bounded to240s wall/1200CPU/8GiB. The full controls receipt is bound to the same executable/source set. All four complete native TIFFs and complete previews are emitted; no crop-only improvement claim is licensed. PNG overview viewing may need an ICC-preserving JPEG copy if the viewer refuses a large PNG; native judgments use<=384px crops.

One limit to retain: source-prior baseline and candidate caches can carry separately measured automatic tone anchors. Within one cache the rendering factorial isolates display changes. Across different source-prior caches, automatic tone changes are a whole-workflow comparison unless the anchors are explicitly held fixed. Neither comparison alone establishes repaired geometry, restored sensor-clipped detail or SOTA.

No source-review blocker remains in the renderer/driver. Actual controls and complete-master identity remain mandatory execution checks. Photographic assessment must protect real reflective grains, blue and colored facets, and dark structure; white-pixel counts or lower brightness are not quality criteria.
