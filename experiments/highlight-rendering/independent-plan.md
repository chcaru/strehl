# Independent highlight rendering controls

Frozen before candidate execution. Author: separate from rendering implementation; root executes. This qualifies a four-arm rendering experiment, not a merge improvement or SOTA result.

Arms: Current; SensorRolloffOff (retain original pinned-sensor clipping); Shoulder (retain sensor desaturation); Both. The author fixes luminance knee0.75, upper asymptote1, exponential shoulder width0.25, RGB scaled by one luminance gain, between current tone placement and current gamut mapper. All arms share current tone anchors, exposure, WB, matrix, MHC and exact cached merged CFA values. No fitting or parameter sweep is licensed.

## Failure inputs and controls

1. **Actual-current identity, not copied expected implementation.** Varied dark, negative-interpolation, neutral, colored, near-sensor-ceiling and pinned camera triples go through `pixel(Current)` and actual production `develop_pixel`. u16 triples must match exactly; at least one tested triple must be pinned and one must exceed the sensor-desaturation knee. This catches a parallel developer path accidentally changing current arithmetic. Current shoulder-inactive replay of the full cached image must additionally equal every sample in the user's existing master; different TIFF metadata does not excuse a pixel mismatch.
2. **Below-threshold literal identity / flat first.** A fixed deterministic noisy but low-level field and dark/colored samples lie below both sensor-desaturation and shoulder knees. All four arms must equal current exactly. The test is about output invariance, not sensor calibration or an estimated temporal noise sigma. Positive hot cases must also demonstrate each factor changes output; otherwise the controls are unexercised.
3. **Neutral highlight levels.** Values through the knee and into `[1,2]` must remain ordered, finite and achromatic through the real pixel function. The shoulder must retain distinct output levels after current has clipped to the same white. A hard-clamped replacement loses those levels and must fail the same check. Negative values and values <=0.75 must be literal shoulder bypasses. Values >0.75 must not increase, must stay positive and <1, and must be strictly increasing across the fixed sampled range. Strict compression is required from0.76; the0.7501 sample can round to identity in f32. This is a functional property, not a photographic quality score.
4. **Genuine bright color.** Several positive non-neutral RGB triples pass through the actual shoulder function; one common positive gain must preserve their channel ratios before gamut mapping. Include negative-channel triples to establish finiteness and the signed common-gain behavior; do not claim this recovers out-of-sRGB colors. With an identity camera matrix and tone[0,1,0], a bright colored pair whose current luminance >1 is forced to white. The shoulder must keep nonzero displayed chroma and distinct bright steps. A grey destroyer must fail the color check. With contrast0, inverse sRGB of the output must recover the source ratio for a moderate colored triple that stays in gamut, within quantization tolerance. Channel-ratio preservation is not perceptual hue constancy and does not establish camera color accuracy.
5. **Retain sensor pin protection.** A raw-neutral triple at all camera ceilings, after WB, must remain achromatic for SensorRolloffOff and Both. A controlled no-pin-clipping alternative must actually be chromatic, demonstrating that the fixture distinguishes disabling desaturation from disabling clipping. Off paths may not silently bypass original `clip_highlights`.

No gradient/sharpness score, white-pixel-count ranking, global brightness ranking or flat-ROI-as-detail metric is used. Exact invariance is a stronger no-harm control below the active ranges; high-range noise may change under the rendering curve and is not claimed improved by that fact.

## Complete photographic assessment

First complete source sets: marigold4 (488 sources) and ore100 (207). The actual current/native merge and fixed candidate-source-prior caches may each feed the rendering factorial, but rendering conclusions must compare the same cache. Source-prior comparisons must hold rendering arm and tone anchors fixed; current-vs-prior auto-tone changes are separately disclosed. Complete native RGB16 outputs and full-image before/after views come before crop discussion.

Full replay eligibility requires exact dimensions, crop/reference, source order/count, every current-baseline pixel equal to the existing user master, finite f32 cached planes of the stated layout, declared WB/exposure/levels/tone, same MHC/ICC and image writer, and per-arm cache hash equality. Cache generation writes one final four-plane scene, not an aligned frame volume. Changing a harmless metadata field must not change image samples; wrong cache shape or nonfinite values must refuse, not silently truncate.

Ore100 protection target: the genuine broad bright granular patch in region[1080,620,640,640], with fixed source70/80 witnesses; adjacent blue texture region[2780,2640,640,640]. AGENTS48 requires384px native viewing tiles: fixed central tiles are[1208,748,384,384] and[2908,2768,384,384]. Larger regions are tiled, never resized for native verdicts. Whole1617px views are orientation and user delivery only. Current has many other real white reflections. **Their disappearance is not an improvement.** Require the same identifiable dark grains/facet boundaries to remain or become more legible, genuine blue/purple/gold variation to remain, and no new purple/cyan glint islands. Native comparison uses unchanged crop/gauge and displays real samples without rescaling. For marigold, protect thin petal/filament boundaries and original yellow/orange distinctions; the marigold specialist freezes exact native regions before candidate inspection.

Each real arm gets independent whole-image plus native assessment. A numerical reduction in clipped pixels or a darker overall appearance is insufficient. A successful shoulder claim is confined to visible highlight gradation/color retained from unchanged merged information; it cannot claim repaired ghost geometry, added spatial resolution, recovery of sensor-clipped detail or SOTA. Failed source-prior general synthetic qualification remains failed even if one photograph looks better. If an arm is null or loses genuine color/detail, close that fixed arm rather than tuning it against one subject.
