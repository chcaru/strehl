# Deterministic row-parallel probe fill

Source candidate, 2026-09-09; no build, fill, RAW decode or performance run by the author. Root owns execution and acceptance. Only gatefloor.rs is changed in product code.

The existing full probe width is twice the full quad width, so every row has an even number of sites. Box-Muller consumes two SplitMix64 draws for two outputs. At the start of active-relative row r, exactly r * full_width draws have been consumed and no spare remains. The parallel row begins at the original seed plus gamma * (r * full_width), with wrapping u64 multiplication/addition. The next() call then performs the same increment as the original stream. Storage origin, stride, padding and odd trailing sensels do not enter that offset.

The old scalar iterator entry remains selectable with STREHL_PROBE_FILL=serial. Unset or parallel selects the candidate. Other values, including non-Unicode values, refuse before writes. The choice is read once per full fill. Validation, complete-quad extent and untouched outside storage remain the same. The RNG/Box-Muller loop from next() through final quantization is byte-identical by source-text comparison before formatting: both draws, f64 ln/sqrt/sin/cos, operation order, round and clamp remain. No full-frame extra buffer, parallel reduction, noise/gain/beta, gather, crop, writer or geometry change.

This algebra is DERIVED, not proof of actual byte identity or speed. Independent controls must compare complete padded buffers with the old scalar stream, including tiny/odd full-quad widths, seeds, layouts, thread counts, saturation and a wrong-row-offset destroyer. Existing M194c tests remain. Actual probe/beta and final TIFF hashes plus alternating native timings decide acceptance; prior full renders are not inferred from scalar equivalence. The native profile's probe phase also includes cloning, gather and measurement; its time is not the fill time alone.
