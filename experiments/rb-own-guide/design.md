# Native red/blue guide experiment

Fixed before execution, 2026-09-19. Generated actual-consumer test only. Root executes;
the author does not run or judge controls. No RAW decoding, full photograph, default
change, axial-offset constant, parameter sweep or claim that axial colour focus
causes the vitamin-C fans. Historical M107 proposes this information path but warns
that independent depths can create false colour at occlusions. BUILD-CHROMA did not
find axial colour focus to explain its speckle/rim defects; M-PHASE0-LCA stopped
before a shifted Rust render because its gain evidence was insufficient.

The canonical actual BandWorker, injected NoiseModel, actual GPU rounded
MHC/Catmull pull, supplied warp/crop, reached Laplacian sizes, SoftPower exponent
schedule, mean fallback, terminal mean and input hull remain fixed. Sources are
2–16 original-u16 generated frames, at most512 native pixels per dimension; no CA
in this first screen. One current source and one pair of transient coefficient
sets are live, never an aligned source volume.

For guide c in R, meanG=(G1+G2)/2, B, E[c,k]=smooth5(L[c,k]^2).
Sixteen independent original-source draws form eight independent pairs. Draws
use the existing injected original-site variances, existing standardized generator,
u16 rounding/headroom refusal and actual GPU gather. Each member then follows the
same real Laplacian transform as the signal. The spatial expected noise energy is
V[c,k]=smooth5(sum_j((L_a[c,k]-L_b[c,k])^2)/16), and floor F=gate*V.
No scalar beta is applied to this already transported variance. Paired differences
retain all reuse, MHC/gather covariance, boundaries and shared-green covariance;
eight pairs remain a finite Monte Carlo estimate, not an exact covariance or a
new camera calibration. Real sensor saturation is not reconstructed or inferred
from u16 container headroom.

Weights are the existing select_weight(max(E-F,0),F,exponent,r_floor), with the
unchanged mean_coarse rule. Existing accumulate_level and finish are reused
literally; nonfinite accumulators refuse the run. R/B terminal means are checked
bitwise against the canonical terminal means. G1/G2 collapsed arrays are copied
exactly from canonical. Final MHC/WB/development is unchanged: delivered RGB green
can still change because MHC uses red/blue structure, so it has an independent
truth guard. No separate hue suppression or clipping adjustment is added.

Five arms share source samples and sixteen gathers: canonical; a bridge identity
using the actual canonical guide AND beta/variance floor; measured-floor green
guidance; R/B own guidance; and swapped R/B guides together with their matching
floors as a destroyer. The matched-green arm isolates guide change from the new
floor estimator. The identity arm uses the production multiplication order and
production per-coefficient accumulation, so exact output is required. The three
experimental arms retain identical canonical green arrays.

Candidate draw seeds are SHA256-derived from active original-u16 content plus a
fixed version namespace and draw number. They do not depend on list index, path
or warp. Identical original data deliberately receive identical draws. Active and
full-storage hashes, all16 seeds, known4 hashes, canonical guide/variance/beta,
per-guide per-band energy/floor/weight hashes and positive counts are recorded.
Canonical gatefloor probe identities are unchanged; source-order attribution must
retain that original evidence if its baseline is index dependent. There is no
probe cache. Any future cache must include source content, injected noise profile,
warp/profile, crop, levels and seed version.

Independent controls own truth scenes, admissions and negative controls. Flat is
scored first. Positive colour-offset and colour-only scenes must beat both the
canonical and matched-green references; neutral edges, unrelated per-channel noise,
crossing depths, genuine radial detail and unclipped detail near a clipped core
can reject. Exact original-green/base/identity, transported-noise factor/routing,
known-wrong guides, source immutability and diagnostic on/off output hashes are
mechanical prerequisites. Neither gradient energy nor a coherent source map is a
quality criterion. A pass admits only consideration of a separate full-size cost
probe;16 GPU gathers per original are still required and speed is unmeasured.

Implementation files are implementation.rs, probe.rs and core-bridge.rs. Root owns
the two feature-gated includes and runner. No previous experiment source is edited.
