## Fixed comparisons and execution

Maximum five fits: flat(identity,phase), then layered(identity,phase,wrong) conditionally. Wrong reads the exact phase observations and identical initializer but applies zero translation tables. Primary target is one original common PSF applied to full96 composed pinhole, scored on fixed64 support; pinhole outputs remain separate. The same-data observed comparator develops each TRAIN CFA and inverse-translates its RGB once to reference before averaging, without another PSF. This baseline carries demosaic/interpolation effects and cannot substitute for original-CFA likelihood evidence. Any donor comparator is explicitly truth-selected from TRAIN only and is never passed to the fitter. Retained known-alpha references are protected external numerical guards, not paired-noise baselines for regenerated data.

Root invokes `phase-aware.py --data ROOT --case flat|layered --geometry identity|phase|wrong --out ARM`. Data manifest schema1 contains config, train/held/reference indices, common translations, `pupil_path`, and `cases[case][identity|phase]` originalu16 paths.
