Block centres and radius comparisons use doubled integer coordinates, including
partial edge blocks. Pool denominators use actual block area, rather than
treating truncated edge blocks as full-sized. Blocks are anchored at cropped
output (0,0). Thus the prescribed +1-quad crop changes their physical phase;
it does not preserve a globally anchored block grid. The resulting constant
weights within 8-square blocks can create boundaries. Whole-interior and local
truth guards must cover that possibility, including the phase case.

Two interpretation constraints are load-bearing. Zero temporal norm removes
neighbour affinity but still pools within the self block; it is not exact
canonical fallback. AllAffinity retains the identical spatial/block operation
while removing the temporal cue, so its participation/output difference must be
reported. Common brightening can make unrelated blocks positively correlated;
the raw-DN cosine is not calibrated noise significance or ownership confidence.
Unchanged injected floor arithmetic does not remove that data-dependent bias.
