## 3. Analytic arm

**DERIVED — model A.** Let each frame supply an independent isotropic Gaussian
gradient vector `g_j`. Then
`X_j = ||g_j||^2 / E[||g_j||^2]` is unit exponential. For `N` frames,

`E[max_j X_j] = H_N = sum(k=1..N, 1/k)`.

The selector therefore contributes `(H_N - 1) V_model` beyond the ordinary
single-sample gradient-noise power `V_model`. If the output averages the `n`
largest independent vectors and their directions remain symmetric, the
variance inflation relative to an ordinary `n`-sample mean is

`I(N,n)^2 = H_N - H_n + 1`,

which is `H_N` at `n=1` and exactly `1` at `n=N`.

**ARGUED — A1.** The i.i.d. analytic term qualifies for the product repair only
if, on both M77 flat controls at gate 0:

* the signed residual power after subtraction is at most 20% of the observed
  selection-excess power in magnitude; and
* the resulting corrected retention is in `[0.80, 1.20]`.

A clamp to zero is a failure, not a pass. If A1 fails, M80 will still report the
term and residual but will not put this idealised order statistic into the
shipping statistic. The real selector elects on a regularised focus field, not
on the two-component gradient used by the acceptance metric, so model A is a
candidate mechanism calculation rather than an assumed implementation model.

## 4. Registered repair if A1 fails

**ARGUED — chosen design.** The fallback is a contemporaneous, cross-fitted
flat-control correction. It estimates the nuisance generated by the actual
stack, gate, focus operator, and frame count instead of transferring a constant
between `N`.

For each output, split the flat ROI into disjoint left and right gradient
regions. Let `P` be measured gradient power and `V` the calibrated model
gradient-noise power. Fit

`k_L^2 = P(flat_L) / V(flat_L)` and
`k_R^2 = P(flat_R) / V(flat_R)`.

For a detail ROI, apply the opposite half's scale:

`V_cf = weighted_mean(k_R^2 V(detail_L), k_L^2 V(detail_R))`

and define signed resolved signal power `Q = P(detail) - V_cf`.
The opposite-half application is fixed now so a run with `detail_roi ==
flat_roi` evaluates each scale away from the samples that fitted it.

The reference is a compact gate-zero selector ROI captured during the existing
second decode pass from the completed winner map. It does not alter the merge.
If its controlled detail powers are `P_0`, `V_0`, each gate reports:

* `STRUCTURE = sqrt(P / V_cf)`;
* `RETENTION = sqrt(max(Q + V_0, 0) / P_0)`.

**DERIVED.** This compares candidate and selector signal at the same reference
noise power. On pure noise, `E[Q]=0`, so `E[RETENTION^2]=1`; on high-SNR detail,
the common `V_0` becomes negligible and `RETENTION` approaches the ratio of
resolved gradient amplitudes. No order-statistic constant is carried across
stacks: `k_L` and `k_R` are re-measured for every gate of every invocation.

**ARGUED — rejected alternatives.**

* A fixed order-statistic subtraction loses if A1 fails because the shipped
  election is not the idealised statistic.
* A single fitted multiplier loses because it transfers the exact quantity
  M77 showed to depend on `N` and gate.
* An even/odd split-half merge loses as the primary repair because each replica
  has only about `N/2` focus samples, changing the subject being accepted; M57
  also measured large independent-half variance in its own candidate.
* A middle-frame or best-frame denominator loses because the first drifts with
  defocus and the second is another selected statistic.

## 5. Acceptance bars fixed before measurement

**ARGUED — N1, real noise null.** On both M77 B2 ROIs, at gates 0 and 4,
`STRUCTURE` must be in `[0.90, 1.10]`. At gate 4, where candidate and selector
are distinct, repaired `RETENTION` must also be in `[0.90, 1.10]`. Gate-zero
retention is one by the reference identity and is reported but is not evidence.
Both stacks must pass; averaging them cannot hide one failure.

**ARGUED — P1, deliberate positive control.** A deterministic 512x512
checkerboard-detail plant with independent Gaussian noise will be evaluated at
synthetic selection scales corresponding to `N = 22, 130, 299`.

* The planted clean signal must lose at least 25% of gradient amplitude under
  the registered 3x3 blur, proving the stimulus can express failure.
* The unblurred arm must report `STRUCTURE >= 3.0` and `RETENTION` in
  `[0.95, 1.05]` at every `N`.
* The blurred arm must report `RETENTION <= 0.80` at every `N`.
* The unblurred retention range across the three `N` values must be at most
  0.05.

**ARGUED — P2, real-detail control.** On both M77 B1 detail ROIs, at gates 0
and 4, `STRUCTURE` must be at least `3.0`. This is a presence-of-detail control,
not a gate-quality verdict.

**ARGUED — C1, falsifying source plant.** A Python script will construct the
source mutation as bytes, write it, re-read it, and require one exact marker
and one exact replacement before running anything. The mutation will bypass
the cross-fitted inflation scale. The targeted null test must exit non-zero and
its message must name the noise-null failure. The script will restore its saved
bytes without `git checkout`, require the original SHA-256 exactly, touch the
Rust source so Cargo recompiles, then require the identical test command to
exit zero.

**ARGUED — C2, observer non-perturbation.** With a private
`CARGO_TARGET_DIR`, two gate-4 runs on the same 22-frame stack, one without
ROIs and one with the repaired invariant enabled, must write byte-identical
merged outputs by SHA-256. Any mismatch fails the repair.

## 6. Constant routing

**ARGUED.** `DETAIL_COLLAPSE_FLOOR = 0.90` will not be changed merely because
the statistic changes. If the new denominator is the full-stack selector and
the controls pass, `0.90` finally denotes a 10% equal-noise amplitude loss
rather than a ratio to an arbitrary middle frame. Whether 10% is the right
product tolerance remains separate; M80 may fix the comparison site, but it
will not tune the value from M80's results.
