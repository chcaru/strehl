# Independent post-collapse mask controls

Freeze before execution. One fourth CLI test under
`merge_cmd::donor_consistency::independent_controls::spatial_controls::`
emits `DONOR_SPATIAL`. Root compiles and executes; this author runs nothing.
Retain the previous three tests and their bars. Generated89x73 odd-domain
u16/f32 sources reuse the independently reset FrameWorkspace and distinct
three-source terminal mean. No original images, simulator calibration, new
quality score or performance claim is involved. Existing180s root control
ceiling applies.

The normative f32 expression is `Bpre + (A - coverage0*BAC)`, followed by the
original per-pixel sample hull. `A` accumulates `m0*donorAC` in supplied source
arrival order. For the real triplet this is source25/28/33, regions2/0/1;
late69 adds regions0/1/2. The fixture uses three overlapping regions, arriving
in region order2/0/1 for three distinct donors and0/1/2 for the single late
donor. Generate a separate literal oracle from original
Pyramids, zero their terminal levels, collapse full-context AC, and only then
multiply the normalized masks. Derive baseline pre-hull and AC independently
from its actual resolved coefficients. Exactly zero coverage must copy actual
baseline post-hull bits. No coefficient-mask approximation is an acceptable
oracle.

Required live failures and guards:

- Asymmetric spatial masks have compact zero support, fractional values and
  sum-over-one overlap. Verify original finest masks with one common divisor,
  exact coverage clamp and normalization count. Shifted odd native origin
  must change the masks, while unchanged input masks pass through exactly;
  existing native geometry test supplies the independent analytic mapping.
- Check per-plane detail accumulators against the literal source-order sum,
  then the full original sample hull. Swapped CFA source planes or separate
  colour masks must fail this oracle. Every plane carries different structure.
- Require more than100 covered changed samples and more than100 zero-coverage
  samples with baseline-exact output. Off and whole-zero states are bit exact.
  Confirm a live difference from old Gaussian coefficient masking on the same
  varying source fixture; this distinguishes operators, not image quality.
- All-ones donor0 and donor2 each must match its full collapsed AC plus actual
  shared mean base within0.02DN after original hull. The fixed shared centre
  pin exercises at least four positive and four negative pre-hull excursions
  greater than100DN; output must equal the exact original pin bound. This
  prevents nominal bounds from passing on an inactive clamp.
- Independently average the three fresh source terminal levels and require
  equality with the actual baseline mean. Require their source bases differ.
  The all-ones result must differ from direct donor data, exposing the retained
  mean base. The finest-mask zero path must not alter this baseline.
- Same-mask wrong late donor must change more than100 output samples. Require
  source storage, consumed planes and ordinary baseline output unchanged.
  Invalid masks, lengths, missing or duplicate donors must refuse.

Literal same-order accumulator and output comparison allows0.003DN; alternate
mean-base algebra allows0.02DN because collapse/addition order differs. Exact
bits apply to masks/coverage, zero/outside outputs, terminal source mean and
immutability. Print worst errors and live counts; do not relax these after a
run. The test shares the public production pyramid kernels, so it verifies
the integration/order choice, not an independent proof of those kernels.

The subsequent full baseline/candidate/late triplet is the quality gate. Keep
the previous supports, donors, tone, geometry and remote controls, showing
native transitions and the competing-depth structure. A single-source noise
increase, copied incorrect detail or spatial seam can pass all arithmetic here;
these are explicit photographic failure modes, not inferred away by the test.
