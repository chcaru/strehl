# One nominated sidecar intervention

2026-09-09. Source-only design after root and verifier found a compact feature persistent in sensor coordinates in both green contacts. The broad stroke-minus-clean contrasts were positive: they do not estimate its attenuation. This intervention asks whether changing the nominated source samples reduces the delivered stroke. It cannot prove physical dust or recover known true radiance. Prefer the existing multiplicative DefectMap sidecar: exclusion would require new validity handling through gather/focus/pyramid consumers and could discard useful detail.

**Frozen nomination and split.** Root manually nominated active-native centre (414,1630) from the already viewed contacts. Support radius32 native; background annulus48..80 native; core radius16 native. Train only original0+104; numerical holdouts26/52/78. All five have already been visually seen, so these are holdouts from shadow fitting, not unseen discovery data. Use only the five saved original u16 patches and recorded phase blacks. No new decoder, detector, support search or threshold sweep. A separate no-treatment location is (414,1440), within the frozen clean region, with identical support/ring sizes.

**One shape, one amplitude.** For each frame and each of R,G1,G2,B independently, fit affine illumination B=a+bX+cY by unweighted least squares using only annulus samples, with X,Y centred/scaled native coordinates. This is a background nuisance, not sensor gain/noise calibration. Require full rank and finite positive predicted B over the annulus and support. V-MOTE/vm_depth.py provides the excluded-annulus affine/quadratic precedent, but its full-frame globals and centre-only return are not a compatible ROI API; retain the small linear algebra, not its old scene driver.

At each quad centre q=(2qx+.5,2qy+.5), freeze phi=cos²(pi*r/64) for r<32, zero elsewhere. The same phi/gain applies to all four photosites of that quad, matching the actual DefectMap. At each phase's own position form residual r=1-S/B from black-subtracted signal S. Fit the single common attenuation A=<phi,r>/<phi,phi>, equally weighting the eight training frame-phase pairs. Emit g(q)=1/(1-A*phi(q)). Require 0<A<=0.2, the existing 1.25 maximum-gain limit; an inadmissible estimate refuses, never clips into an apparently valid map. No per-phase shadow gains, fitted width or heldout shadow refit.

**Fixed gates on this local model.** Evaluate a second, quadratic annular background with basis1,X,Y,X²,XY,Y² as the single nuisance stress. It does not produce a second map or alter A. For both background choices, each phase must have median_core(1-S/B)>=0.010 in at least four of five originals, and the median of those five core depths must be >=0.015. These inherit the existing validator's frame-depth/presence and depth magnitudes, but are explicitly local per-phase model checks, not a reproduction of its full-context p-value.

Apply the proposed map with the existing f32 black-subtracted gain/rounding and white-clipping disposition. On each heldout original and each phase, under both background models, support32 RMSE of S'/B-1 and its absolute mean must not exceed their uncorrected values; corrected core median S'/B-1 must not exceed +0.010. No new clipped/skipped-white sites are admitted. Retain before/after means and differences in real DN as descriptive observations; normalized model residuals are not ground-truth image errors. A failure stops this proposal without changing the radius, model, gain or bars.

**Small rejecting controls, same decision.** The clean nomination must produce no treatment. Place a finite scene-following dark feature on copies of the saved clean backgrounds using the held five maps; the same persistence gate must refuse it. Label this manipulation a coordinate/model falsifier, not a photon simulation. The verifier also owns an independently specified stationary positive input, doubled-amplitude overcorrection, and a changed-heldout witness: altering heldouts cannot alter the fitted A but must be able to fail admission. Every original sample outside the exact emitted quad mask must remain u16-bit-identical; the scalar correction/black/clipping controls check the actual path. Originals on disk are never modified.

**Production boundary and limitation.** Serialize only this connected nominated profile through the current v2 map format, with per-stack provenance and actual sensor/covered geometry; no embedded/global profile change. An enabled STREHL_DEFECT_MAP reaches stack.rs::defect_preflight and apply_defects before warp; explicit STREHL_DEFECT=off would override it. Keep the shipped preflight unchanged: eight evenly spaced full originals, hp64/two passes, window560 and annulus60..400 quads, with its existing refusal rules. The saved small patches cannot reproduce that context. This is an explicitly additional production read, not a claim that five patches passed its validator.

The validator rescales the supplied profile as exp(log(g)*scale) using its eight frames. Record its actual scale/depth/presence/refusal and live correction counts; the numerical holdouts validate the proposed amplitude only. The existing corrector does not propagate gain² into the noise variance, so this allocation is a finite visual causal test, with no promotion or noise-fidelity claim. Record output tone parameters; demosaic, pyramid support and automatic sRGB tone can spread delivered changes beyond the raw mask. Require exact preservation outside support at the original-CFA correction boundary, not falsely at every TIFF pixel. If enabled correction is refused, changes nothing, leaves the stroke, creates a bright spot or visibly harms adjacent structure, report that outcome and stop. A useful local output change may establish contribution of these source samples without establishing physical dust.
