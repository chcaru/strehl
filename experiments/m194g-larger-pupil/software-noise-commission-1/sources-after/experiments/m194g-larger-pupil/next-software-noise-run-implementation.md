# Software-noise controller: source-only implementation handoff

The held contract `4e92e176` and interface `98048ba6` define the law, fixed
1186-call private population, 17 deterministic records and separate 90-file
emission. The controller and authority helper have received AST-only parsing;
no numerical module import, sampler, encoder, reader or control has executed.

`software-noise-run.py` checks an externally pinned execution release against
the actual original interpreter arguments before importing the core. It then
loads the checked core, authority helper and independent reader bytes, in that
order. The separate externally pinned runtime manifest must describe that
startup. One Budget starts at script entry, before setup, and covers the
complete stage. The committed core and frozen optical producers remain held.

Private execution consumes the fixed schedule, records both raw and consumed
stages as contracted, and performs independent actual-key/entropy checks
before sampling. The deterministic resource control injects an expired weak
entry under the live owner's ID and checks replacement, alias accounting and
an oversize refusal. The persisted private index is retained if subsequent
reading fails. The independent full reader and its 36 retained-file controls
run once on the same Budget/store; each returned result is persisted before
its status is checked. No reader failure is replaced by a success wrapper.

`independent_reader` references a small command record with exactly schema,
status, read and controls. Its schema is
`m194g-software-noise-reader-command-v1`; success is
`PASS_SOFTWARE_NOISE_PRIVATE_TRACES`. The two children are the exact separately
persisted reader/control results. This concretizes the interface's FileRef
without changing its top-level fields. Emission also checks the full reader's
actual index association and the controls' complete-reader companion hash.

`software-noise-authority.py` consumes the externally pinned genuine full-float
authority, the exact child comparison/component records and all five render
results. It associates the five original primary receipts and scalar refs,
requires typed native geometry and checks one bounded NPY byte buffer before
allocation. Duplicate header keys, changed payloads, incomplete terminal
metadata and aliased primary file identities refuse. No optical method is
imported. Emission consumes a validated 18-bundle/90-frame plan and requires
the completed matrix to match it. It produces only uncommissioned CFA files;
the later independent CFA gate remains a separate boundary.

Finalization rehashes source/input/runtime bindings and the actual saved
payload references after required reader/control/source persistence. It
checks source/input/runtime, output extent and the same elapsed limits again
after writing the terminal result. Its recorded work is the pre-terminal
receipt; successful process return requires the later checks as well. A
post-write refusal retains the first terminal bytes under a rejected name and
attempts an explicitly failed record. Partial terminal bytes remain counted.
The original numerical/reader exception is retained alongside secondary
capture or persistence failures; stderr carries the complete failed record if
the filesystem cannot save it. These are source contracts, not executed
failure-path evidence or a claim that the fixed work budgets will pass.

Exact CLI remains the held interface: `--mode commission|intended --output
NEWDIR --runtime PATH --runtime-sha256 SHA --execution-release PATH
--execution-release-sha256 SHA`; intended adds the two externally pinned
float/noise commission pairs. Root commits source and exact commands before
any import or execution. Genuine full-array admission remains a prerequisite
to the planned first-draw release.
