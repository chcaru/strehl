## Literal private choices

The principal small grid is9×6, normal(1,.25), offset2, depths(1,2), K2,
inverse foci(.5,.75,1,1.25,1.5), original indices0..4. Use constant fields
15000/12000 solely as legal model records: no field evaluation is permitted.
The nonidentity map is scale2, rotation0, centre(.5,−.5),
translation(1.25,−.75). These dyadic coefficients give exact inverse-affine
geometry and both layers plus coupled cells; actual occurrence is required,
not inferred from the description. Zero and both foreground-defocus signs
must occur. The three registered integration arms retain their exact orders.

Smaller limit/coverage fault cases use2×1 cells and an explicitly full or
absent mask, legal private frames and the same model API, so limits must be
checked when no numerical helper runs. Single-cell rule/cut cases rechoose
coordinates from this model by a documented fixed finite search if needed
for a live negative-height or cancellation witness; the search chooses a
geometry diagnostic, not an image-quality result or new tolerance. Every
selected witness and the complete searched set are retained, including a
failure to find the required distinction. No radiance is used in selection.

## Controls and deciding failures

1. **Pinned fixture/schema/source:** independently compare the literal fixture
   with the registered values; wrong external hash, unknown/missing field,
   bool/float integer field, wrong schema, duplicate index/arm, changed frame
   or scene binding must refuse at the boundary that claims to validate it.
   A private small model is explicitly a private API input, never a newly
   trusted intended fixture. Preserve unchanged valid fixture companions.
2. **Loaded module identity:** prepopulate `sys.modules['model']` with a
   different sentinel module and verify the loader still binds frozen
   render functions to the actual pinned model, restoring prior state on
   success and error. Wrong source bytes/hash, missing source and a coherent
   wrong imported model must not be admitted as the pinned pair. Copies used
   for faults live only in the independent output directory. Inspect actual
   module paths/functions and before/after source hashes, not filenames alone.
3. **Coverage:** compare actual visited `(arm,index,x,y)` with a separately
   constructed Cartesian set, and count each once. Missing last cell/frame,
   duplicate cell replacing a missing cell, wrong index/coordinate, omitted
   arm and reordered valid enumeration are distinguishable. Reordered valid
   traversal may change the ordered digest but must preserve counts and set.
4. **Rules/mass/work:** call the actual frozen geometric helpers independently
   for the private population and inspect their returned root geometry and
   low/high rule shapes. Require80 points/root for primary and angle arms,
   320 for cell-refined; angular nodes use the actual nonempty cuts times48
   or96. Point multiplicity is evaluation work even if coordinates repeat.
   Remove a low rule, one negative-height ladder contribution or one root;
   alter one rule's mass by a fixed1e−6 relative factor. Each live mutant must
   violate the relevant work or mass assertion; do not silently renormalize.
5. **Counter heights:** compare the actual cut stream with the frozen
   `render_points` inverse-then-dot sequence, signed alpha and `native_mask`
   radius. A cancellation/negative-height witness must distinguish replacing
   those heights with selector or precombined-plane heights. Record both
   cuts and actual affected node counts; ordinary dyadic companions must
   remain valid. Zeno independently commissions the geometry selector math.
6. **Strict limits and persistent clocks:** use private injected clocks, not
   sleeps. At each point/node threshold, the exact threshold refuses and a
   just-below companion passes. An actual counter with a small registered
   limit must stop before completion when its consumed total crosses it.
   Advance the clock across analytic-only cells, frame transitions and arm
   transitions so a resetting timer would falsely pass; require the whole-run
   timer to refuse and preserve partial evidence. CPU and wall faults are
   distinct, with a stationary-clock valid companion.
7. **Array ownership:** a contiguous float64 backing array of128 elements is
   1024 bytes. Two overlapping views share that allocation; a separate copy
   adds another1024 bytes. A boundary1024-byte companion may pass the declared
   non-strict storage cap, while retaining the copy must refuse. Released
   backing storage must cease to count as live. Cover actual returned low/high
   rule arrays and cached rule arrays at the wrapper boundary. This is tracked
   owned ndarray storage, not RSS or a claim about all library temporaries.
8. **Guard and forbidden work:** a deliberately insufficient private rational
   bit budget must yield unchanged numerical fallback on a valid coefficient
   set, never a perturbed coefficient or false analytic admission. Invalid
   budget types must refuse. Patch radiance/point-integral/Bessel entry points
   with recording traps during valid geometry runs; all call counts must be
   zero. Independently require real selector, rule and cut activity so the
   zero-radiance observation cannot be explained by skipping traversal.

## Evidence and scope

Coordinate/resource faults may use explicitly named private injection seams
or patches to the actual counter's helper calls. Those patches do not create
valid final source authority and never change frozen M194e files. API names
will be aligned with Curie before dependent implementation. If an asserted
failure turns out to be a misunderstanding of the exposed contract, preserve
the first result and document the correction rather than deleting it.

Each invocation records interpreter arguments, versions, fresh cache path,
source snapshots and before/after hashes, all check rows and terminal status.
No intended large counter, radiance calculation or later float gate is
authorized by this component design. An independent numerical comparison and
its separately frozen resource budget remain future work.
