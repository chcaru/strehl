## Consumer and implementation boundary

The consumer is the existing `run_pyramid_prepared` production fold and TIFF
writer. A new test-local `noise-pupil-bridge.rs` supplies admitted decoded CFA
frames through `PyramidFrameSource`, as M194f already does. Keep the M194f
64×48/noise-off input contract and its frozen sources unchanged. Its domain,
byte count and black-level lower bound are wrong for this larger noise law;
loosening that schema would silently change the meaning of its old admission.
The new module has its own explicit M194g environment namespace and schemas.
No alternate merge, demosaic, noise estimator or product default is introduced.

The input is the externally pinned `m194g-software-noise-admission-v1` record,
status `PASS_SOFTWARE_NOISE_FILES_ONLY`. Reopen its five repository-relative
children and require the genuine completed generation, independent read and
both prerequisite commissions. Reopen the exact manifest and verify its
closed geometry, sensor and complete18-bundle/90-frame population. Match the
requested scene and exact noise-off/null-seed or registered seed tuple; a
descriptive bundle label cannot select different CFA bytes. Read path roots
exactly as the noise interface declares. Require bounded JSON with duplicate
and unknown-key rejection, typed integer fields, canonical contained paths,
distinct actual frame identities and all file hashes/lengths. An externally
repinned invented authority is not something these consistency checks can
authenticate; the command's actual pin comes from the independent admission.

Each selected source is original little-endian u16[240,320],153600 bytes,
active origin0, stride320, full active extent. Read/hash the same bounded
buffer that supplies its decoded samples. Permit the declared CFA interval
[0,15360], including values below black512. Retain the generation's separate
zero-clipping admission; checking decoded bounds cannot reconstruct a
pre-clipping excursion. Planning may stream all declared payload bindings,
but retains no decoded stack. Each actual decode owns one u16 CFA buffer,
with no materialized aligned stack and no RAW-decoder fallback. Missing RAW
sentinels cannot supply decoded pixels. The unchanged full-resolution gather
still attempts its metadata identity lookup; the local identity reader returns
`CaptureIdentity::EMPTY` when opening that sentinel fails. This tolerated
metadata lookup is not a proof of zero file-open attempts. CA stays explicitly
off.

Inject the exact four-plane gain .25DN/e and read noise4e with black512 and
white15360. Frame and writer white balance use the registered f32 values
[1.3333333730697632,1,1.6666666269302368]. The emitter did not apply WB. Keep
the existing production noise provenance convention for synthetic injected
coefficients; make no physical sensor-calibration claim. CFA factors and the
noise law precede gain/encoding; do not replace them with a post-RGB sigma.

noise-off/noisy inputs and both admission modes. Separate private fixtures

already commissioned constant, affine, channel and rank controls where their
