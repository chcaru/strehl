## Choices checked and corrections requested

- The author wrapper must retain one cumulative component work/time allowance
  through ordinary cases, methods, cache setup, mutations, restored calls and
  all four observer executions. Its component `new_frame` deliberately avoids
  the unchanged fallback Meter's per-frame reset. The separate full-image arm
  keeps per-frame work allowances and one arm clock. This is a code-path
  observation; actual crossing controls still have to demonstrate enforcement.
- A file hash followed by a second path read does not bind the parsed bytes.
  Author frame loading and reference JSON/historical-array loading must parse
  the same bounded bytes they hash. Array readers must check the NPY header's
  allocation, dtype and shape before loading its numeric payload.
- Counting only the arrays passed in one registration misses separately
  registered live copies. The reference now has weak backing-owner accounting
  across registrations and an explicit one-live-scalar-frame guard. Aliases
  must share one charge; distinct live copies must accumulate. This tracks
  named ndarray backing allocations, not RSS or hidden library temporaries.
- Final source capture or persistence must not replace an original numerical
  exception. Keep secondary errors separately, and check elapsed limits after
  required persistence before treating the process's result as successful.
  Only the completed process and its final pinned record can be admitted.
- Private refusal controls must identify their expected exception class and
  consumer boundary. An arbitrary harness exception is not the intended
  refusal. A memory copy is described as a memory copy; the reader also needs
  an actual saved-and-reopened valid payload companion.
- The registered missing `1/pi` pupil normalization scales the complete
  integral. A draft reference fault changed only wave transfer factors while
  leaving DC/affine normalized. The corrected consuming fault scales the
  entire scalar and records the intervention. No phase, amplitude, target or
  discrepancy threshold was changed to improve fault power.
- Observer evidence must name consumed negative, zero and positive selected
  defocus, as well as both selected layers and actual wave work. Configured
  foci or unused cache entries alone do not establish those paths were used.
- The author mutation writer zipped a reopened JSON object's iteration order
  with the reader's fixed array order. Canonical JSON sorts keys, so this
  would assign scalar data to the branch file and break even the restored
  companion. Use explicit scalar/branch/index/diagnostic names when writing.
- Fault identifiers are lineage for mutated, cache-prime and restored rows;
  only the mutated phase activates the intervention. A draft controller
  applied it in all three phases, asking for a stale-cache key before priming
  and repeating each defect in its purported restored companion. Validate
  phase/method/call explicitly and separate metadata from active behavior.
- The independent reference author re-chose the author's cache path and found
  that a transposed-frequency fault could retrieve previously correct factors:
  the draft key named the matrix and original frequency but omitted the actual
  transformed wave vector being consumed. Include that actual vector in the
  key. This was source-path evidence of a possible inert fault, not a measured
  failure or a reason to change the registered target.
- Set the declared numerical thread environment before the first NumPy import.
  Loading the old helper later cannot retroactively establish the new import
  path's environment. Record actual environment and Python/NumPy/SciPy versions
  in both author entry points, alongside the elapsed counters.
