## What exists, and what its controls cover

`FloatAuthority.__init__` consumes an externally pinned full-float gate,
its actual comparison/component records and five complete render roles. It
checks the admitted projection, original primary frame order, input geometry,
receipt/scalar association, typed shape and finite nonnegative scalar data.
The bounded NPY parser rejects duplicate dictionary keys before evaluation,
wrong shape/dtype/order and extra/short payload. Paths and underlying file
identities are checked for aliases. `scalar` rereads one primary array;
`finish` rehashes observed inputs. No optical producer is imported.

These are implemented guards, **not commissioned outcomes**. The independent
private noise reader's 36 controls exercise its own complete-index, trace,
encoding and NPY paths. They do not instantiate `FloatAuthority` or invoke
its `scalar`/`finish` methods. The producer's `resource_control` is unrelated
to that authority chain. A search by symbols and filenames found no separate
noise-authority private-control caller in the current M194g source set.

Before intended emission, the actual authority entrypoint needs a valid
genuine-gate companion and controlled failures for: incomplete/error-bearing
comparison or render child; wrong admitted projection; bool/index or reference
gauge changes; swapped/refined primary substitution; receipt/scalar association;
duplicate file identity; missing/changed source input; and same-buffer NPY
duplicate-key/huge-header/object/short/appended/nonfinite data. Re-seal the
relevant ancestor references so the intended consuming check is reached.
Call `scalar` and `finish` too, including an actual changed-file-between-reads
case. A fixture-only synthetic authority can commission parser branches
early, but must be explicitly ineligible as a genuine optical authority.
No extra noise draws are needed.

## The actual 90-file read is absent

`independent-noise-reader.py` implements the private 1,186-trace commission,
its controls and final private-file reread. It has **no intended-CFA reader or
admission writer**. The interface describes a later
`PASS_SOFTWARE_NOISE_FILES_ONLY` gate, but no implementation emits it.
The producer correctly returns `COMPLETE_NOISE_FILES_UNCOMMISSIONED` for
intended generation. Neither that status nor a private noise-law pass can
substitute for reading the actual 90 files.

The smallest next independent module should accept externally pinned manifest
and generation-result files, consume the exact existing interface, and:

1. Bind the completed generation result to its actual manifest, runtime,
   source/command/input closure, full-float authority and private-noise read
   plus controls. Require successful terminal checks, not a partial package.
2. Enumerate the exact two scenes × nine states × five original frames in
   order; require 18 bundles/90 distinct file identities, reference 2,
   identity placement, typed native 320×240 RGGB geometry, sensor values,
   and explicit manifest-parent versus repository reference roots.
3. Read every actual 153600-byte headerless little-endian u16 CFA. Check
   hashes, extents and the **inclusive [0,15360] range**. Values below black
   512 are valid. Read actual audits and require typed zero pre-clipping rail
   counts, correct tuple keys/calls, null seed/streams for noise-off, and
   corresponding source/runtime lineage.
4. Independently reconstruct all ten noise-off files: textured from the
   admitted original primary scalar arrays and flat from constant 12000,
   applying float64 photosite factors before the exact ties-even/rail encoder.
   The other 80 Q files are read exactly, without resampling or pretending
   their unretained P/R/X values have been reconstructed.
5. Commission that actual reader entrypoint using valid/restored companions
   and rehashed missing/duplicate/mislabeled tuples, bool fields, wrong factor/
   origin/gauge/stream metadata, one-code noise-off changes, truncated/
   appended CFA, and wrong sample-range/rail records. Include a valid
   below-black sample so the obsolete M194f minimum512 rule is a powered
   destroyer. Include an above-white value for the opposite bound.
6. Rehash the consumed source/input/output set after required persistence,
   then emit the interface's five-reference independent gate. It remains
   software-file admission, not physical calibration or product quality.

Saved noisy rail/intermediate hashes are producer observations bound through
the commissioned source and actual run. Q alone cannot prove that an
unretained X was within rails: e.g. an X just above white can round to white.
The intended reader must state that limit, require the actual audit, and avoid
inventing additional draws or full intermediate traces.

One execution-design choice remains to freeze before that module runs: either
share the existing intended-stage Budget through final reading/persistence,
or register a separately named post-generation read-only verification budget.
Starting a fresh intended-generation budget merely to evade its already
consumed cap is not permitted. The current interface's separate final
generation-result reference makes this boundary worth specifying explicitly.
