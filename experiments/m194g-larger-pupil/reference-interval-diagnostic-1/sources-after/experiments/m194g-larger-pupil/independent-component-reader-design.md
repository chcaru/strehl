## Coverage and independent choices

Build the expected call keys from the externally pinned catalog, never from
successful output rows. It names 150 cases: 149 cells with both
analytic-enabled and analytic-disabled calls, plus one frozen-point call.
Each case names its author arm and both primary/refined reference arms.
Thus the ordinary author population is 299 calls and the reference population
is 300 values. Require exact case/arm/method coverage, not just those totals.
Preserve each actual baseline, named fault and restored companion distinctly;
a refusal or absent required value cannot become a smaller successful sample.

Compare every ordinary author value, and each restored value, with both
independent reference values using maximum absolute discrepancy <= .004 e.
Require all 150 independent primary/refined discrepancies <= .0005 e.
Derive the textured ID set before looking at results: a case is textured when
either resolved field contains a nonzero affine coefficient or a nonzero wave
amplitude. Report the exact IDs and apply RMS <= .0008 e separately for each
author method/arm against each reference arm. This prevents two methods or
two reference precisions from diluting one another's discrepancies. Also
report the combined textured RMS descriptively; do not replace the fixed
per-case maximum with an aggregate. These values concern this deterministic
optical calculation, not a temporal-noise or quality score.

Read the independent literal-oracle evidence, then separately check the joint
point against `11000 + 400/pi`, the zero-pupil cell against 13816 e, all four
equal-field visibility nulls against 12000 e, and the zero-frequency full and
absent cases against 11000 e. The affine coordinate case uses the actual
stored finite inverse mapping and the average of an affine field over the
transformed cell; it does not use the author's scalar result as its reference.
The retained three whole-cell array samples must be read from the catalog's
externally bound original arrays at the stated y/x coordinates. These are
different checks with different dependencies, not independent repetitions of
one numerical method. The spatial reference lane owns the rational disc
series, independent quadrature, tangency and joint-sample mathematical proof.

Require the actual consuming fault value for each of the 14 fixed target IDs
to differ from both independent references by strictly more than .004 e.
Equality at the threshold is not power. The matching baseline/restored calls
must satisfy the ordinary bar. A claimed `passed: true`, a nonzero configured
amplitude, an error-field edit, or an unused changed cache key cannot replace
the actual value and consumed-path witness. Preserve and report any inert
fault; do not retune its phase, target, amplitude or threshold. The three
declared refusal targets must reach their actual consumer and refuse, with a
reopened valid companion. Equal-field visibility values are explicit scalar
nulls and provide no evidence of correct branch selection.

## Actual persisted observer payloads

Read all four fixed executions, all three arms and all five frames: 60 frame
packages, 3240 scalar sites. Compare corresponding same-arm frames by actual
bytes for all four payload arrays, not file names or summary hashes alone.
Keep one comparison pair in memory; never load all 60 frames together.
The four arrays are scalar `<f8[6,9]`, branch `u1[6,9]`, numerical-site indices
`<u4[N]`, and diagnostics `<f8[N,4]`. Require finite scalars, exactly the three
branch codes, sorted unique indices exactly equal to the branch-2 sites,
finite nonnegative diagnostics, and the registered column order. Check the
value-indicator sum identity against the actual columns. That identity is
serialization arithmetic; it is not an independent error bound. Analytic sites
must have no fabricated sparse diagnostic row.

Require background at (0,0), foreground at (8,5), and numerical at (4,3)
through the actual branch arrays for every frame/arm. Check all coordinate
coverage against the fixed 54-site grid; reversal is the complete reversed
cell order while frame/arm order stays fixed. Scalar and sorted diagnostic
bytes must match, while the actual ordered traversal witness must change.
Require actual count and placebo hook calls, positive count collection and
zero off/placebo collection. Require consumed full-layer wave witnesses for
both selected layers and zero/nonzero selected defocus; the configured input
alone cannot prove the implementation reached those paths.

Run the named scalar +1 e, duplicate/omitted coordinate and diagnostic +.01 e
faults at frame 2, primary, (4,3), with literal reopened restored companions.
The diagnostic fault changes only `cell_quadrature_delta_e`; it can satisfy
the sum identity and still must fail byte equality. Independently re-choose
semantic corruptions: missing numerical row, extra analytic row, duplicate
or unsorted index, out-of-range index, invalid branch code, a finite scalar
change on an analytic site, NaN/Inf, negative indicator, swapped columns,
wrong dtype/endianness, wrong shape, an omitted frame and a duplicate frame
replacing a different arm. Rehash the altered files and outer fixture records
so these reach semantic/equality consumers rather than stopping at an old
checksum. Some column swaps may preserve the sum identity; byte comparison
must still detect them. No requirement that independent integration methods
have equal bytes is introduced.

## Binding, typed boundaries and reader commissioning

Externally pin the actual completed author and reference result records and
the source/command release. Read bounded files once, hash the same bytes that
are parsed, use duplicate-key/nonfinite-rejecting JSON and disallow pickle
when reading NPY. Use the authors' concrete closed schemas after they are
fixed; reject unknown/missing keys, booleans in integer slots, floats in index
or count slots, invalid method/arm/status and nonterminal packages. Source
bindings must include the actual author/reference/reader modules, pinned
original helpers, catalog, resolved specification and source snapshots, with
the released source set and before/after equality. Missing/substituted included
sources cannot be excused by an unchanged top-level source digest. Snapshot
bytes attest the recorded revision; later workspace edits are not silently
projected into the original run.

FileRefs resolve relative to their declared containing package, never to the
current working directory. Require hash and byte length, bounded relative
paths, exact array dtype/shape and unique required payload paths. Reject
absolute/traversal/outside-resolved paths, alternate-source substitutions,
wrong external pins and actual changed-file bytes. A complete private package
relocated with unchanged bytes remains the valid companion. Record all exact
paths and pins in the independent invocation. Fully forged telemetry is not
authenticated by recorded-consistency checks; actual source inspection and
live controls are still required.

Private reader fixtures will be labeled `fixture-only`, never emitted as
genuine numerical authority. They exercise missing/duplicate calls, a swapped
author method, one missing reference arm, a copied reference mislabeled as the
other arm, changed input/catalog/source records, unknown fields, invalid
numeric types and coherent finite value/error changes. Fixed numeric vectors
exercise each <= threshold at equality and above it, RMS failure while all
individual values meet .004 e, a one-case maximum failure hidden in aggregate,
and fault power strictly above .004 e. Actual scientific results remain
separate. The reader accepts restored controls and refuses every mutated
package on its intended boundary; it does not treat its own expected label as
the test outcome.

## Resource and entry path controls

Inspect and test the actual new author Budget and reference limiter after
their APIs freeze. Use injected clocks and small explicit buffers, not an
intended frame. For the author component scope, test CPU 599.999/600/600.001,
wall 1199.999/1200/1200.001, point count 15999999/16000000/16000001,
angular count 2399999999/2400000000/2400000001, pair count 32767/32768/32769,
and the 32 MiB storage limit at equality and above. The work and storage caps
are inclusive here, unlike the earlier strictly-below geometry cost caps.
Reference integrand count uses 29999999/30000000/30000001. Use small-cap
array companions plus a real 32 MiB allocation if needed for the real boundary;
aliases/views must share one backing and distinct live copies must accumulate.

Prove that elapsed time and cumulative component work are not reset across
cases, methods, observer modes, frames, faults, restored calls, cache setup
or final persistence. Exercise an actual analytic-only call and a clock
crossing before terminal success, so a frozen Meter that only runs inside
fallback cannot leave that path unmetered. Exercise one second-frame retention
fault and a released first-frame companion. Refusal evidence must preserve
the original exception when a final source capture also fails. Startup/import
errors remain externally captured launch failures, not invented result files.
No complete image or radiance-heavy control is required for these plumbing
checks; exact API fixtures and commands will be frozen before execution.

The final reader checks actual work totals, finite/nonnegative clocks, source
closure and complete deciding controls; it cannot infer actual enforcement
from an under-cap summary alone. Initial timestamps must cover required setup,
and exact interpreter arguments, fresh cache prefix, library versions,
thread environment, source snapshots and parent command records remain part
of the record. Cooperative time checks are not an operating-system deadline,
and tracked explicit ndarray backing bytes are not RSS or hidden allocations.

`independent-component-controls.py` under this allocation. Concrete interface
bindings and exact commands will be recorded before running either script.
