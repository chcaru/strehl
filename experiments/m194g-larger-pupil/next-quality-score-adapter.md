## Complete scorer data flow

objects, full K0 scalar, fixed geometry/fixture, same Budget and an actual

paired-MSE, paired-variance, sparse and noise-off-wave tables. The kernel

converts code to post-WB DN by14848/65535, with no black subtraction.

Process one scene at a time. Keep two noise-off RGB arrays, six two-dimensional
mean/M2 states, two shared plane scratch arrays and one ideal channel plane.
Only textured processing holds its two actual endpoint RGB references. Load
one paired seed at a time and release it before the next; reopen each matched

complete stage to108, below the registered256 ceiling; no reuse of a copied
receipt can replace actual pixel reads. No temporal image volume is stored.

pass. It retains all values, exact individual inputs, targets and masks, all
repeat and channel rows, and descriptive review triggers separately. Missing
rows, unpowered instruments, refused targets/resources or changed sources
produce `UNCOMMISSIONED_QUALITY_SCORE` with retained partial evidence.
