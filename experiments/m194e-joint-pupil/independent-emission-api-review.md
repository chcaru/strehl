## Design and actual scope

The root-approved [prospective design](independent-emission-design.md) preceded
implementation. The [concrete contract](emission-contract.md) clarified that
array children inside a numerical receipt resolve from that receipt's parent,
while bundle frame references resolve from the bundle's parent. This clarification
was read before the first API test. Historical `author_root` permits byte-identical
package relocation with preserved hierarchy; source/control/evidence references
retain their repository base. Neither the original informal blanket reference-base
description nor an invented M194b schema was used to judge the implementation.

The driver calls the actual `convert_cfa`, `emit_cfa_bundle` and strict schema APIs.
Its complete private fixture has three arms of five distinct48×64 scalar arrays,
scalar values `12000 + 4*x + 8*y + 16*frame`, zero illustrative error indicators,
and explicitly invented numerical work records. These floats do not purport to
render the declared optical scene. The separately trusted fixture gate exercises
the API's admission condition and has no scientific authority. In the first run,
the genuine current-source author component record `author-controls-5/result.json`
was copied unchanged, SHA-256
`c6bb3141e9807255b147ffa0925e5355f65e76ce900a3d77d01379b98f472215`;
all135 checks and all six source bindings were checked before reuse. This is
component provenance, not independent mathematical admission of the fake floats.

Three different assertions are kept separate:

- Rehashed finite array, foreign-frame and control changes must fail against the
  original external gate digest. A candidate cannot authorize its own denominator.
- Closed-schema semantic tests use a newly bound **private fixture** gate, so
  unknown types, models, numerical settings and malformed actual arrays are
  challenged beyond stale checksums. This does not claim authentication of a
  completely forged scientific experiment.
- After valid emission, actual u16/electron samples are changed and their
  descriptors rehashed. The independent scalar oracle checks values directly,
  bypassing the now-stale emission receipt so a metadata failure cannot stand
  in for the value test.
