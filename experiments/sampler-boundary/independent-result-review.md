   after direct Cargo0 and EOF is distinguished from generic termination.

2. Full scalar population. Independently enumerate the fixed344 unique IDs,
   group totals, kernel names, API roles, query coordinates and expected

   compare with the saved oracle field as well as actual output. Re-evaluate
   actual-versus-paired finite comparisons for translated-stencil and
   must-differ rows with the frozen tolerance. A missing, duplicated,
   out-of-order, changed-coordinate or falsely passed row must fail this
   population review. A genuinely numerical failing row remains a result,
   not a metadata failure that can erase the baseline.

3. Power and coupling. Check the saved actual wrong-translation/wrong-phase
   pairs, restored pairs, raw/clamped cubic values and effective fallback
   endpoint/far-high values. Where complete stored operands suffice, recheck
   the corresponding predicate. Where a reported exercise flag involves
   unsaved tap arrays or changed-input counts, label it a source-bound
   reported witness and do not claim independent reconstruction of that
   runtime observation. Paired Lanczos calls are coupled translation tests;
   they are not independent estimates or absolute first-moment truth. A DC
   pass alone could hide the coordinate defect and is therefore only a null
   and regression control. The limiter hull could hide shared coordinate
   shifts and cannot replace the coordinate criterion.

4. Full gather reconstruction. Decode every one of the12288 row-major

   worst-error summary; a count-only agreement cannot admit a reversed map.
   The opposite map has the same accepted integer set, so values must
   discriminate it after a successful actual mask/count population.

### Admission language and remaining limits

This audit can establish fixed software contract behavior and actual result
association. It cannot establish every signal, all arbitrary coordinates,
unchecked NaN safety, nonfinite sample-data behavior, physical geometry,
native CFA conversion, sharpness, quality, performance, a resampler ranking,
a changed default or SOTA. Literal controls establish the claimed property
only on their specified scalar inputs. Deterministic nulls have no estimated
statistical standard error; no noisy-effect ratio or statistical replication
is inferred.
