### Bound and permissible operations

Proposed to root before saved results: at most four saved-read invocations,
each at most10 process CPU seconds and15 active-wall seconds, up to768MiB
total actual file bytes read, at most128MiB per file, and up to8MiB new
retained review/ledger output. These are prospective audit bounds, not measured
resource use or extra build/test authority. Root must release saved reading
before it starts. Unused capacity does not authorize additional science.

The four slices are baseline transport/scalars, baseline full gather,
repaired transport/scalars plus thirteen regression outcomes, and paired
gather/source-delta audit. Small source-only authoring reads are separate from
future result reads. Each actual read records path, bytes and digest; each
invocation records its own command, exact exit and process CPU/active wall.
A cap or unexpected missing/invalid artifact is reported without a retry that
silently erases its cost. Report composition may quote those saved ledgers.

No controller/helper import, Rust invocation, sampler evaluation, numerical
fixture generation, image decoding, real capture, broad process inspection,
attachment or termination is allowed. The only numeric work is interpretation
of already saved scalar bit words and masks against the frozen fixed literal
contracts. The review does not introduce another input population or sweep.

### Independent choices and falsifiers

1. Transport and association. Start from root's exact frozen release and
   six-role external bundle, then follow the actual references, not a positive
   status alone. Check byte extent, digest and canonical path identity;
   raw child/controller/external exit, complete pipe drain/EOF, terminal owned
   Job active count, cleanup classification and resource accounting. Require
   fresh Compiling and actual non-fresh Cargo artifact identities for both
   targets, exact child arguments and source associations. A dropped tail,
   unconsumed stream, arbitrary crash101, stale or differently sourced
   executable, surviving Job process, emergency termination or cap overrun
   must prevent an operational-completion conclusion. Compile-only cleanup
   after direct Cargo0 and EOF is distinguished from generic termination.

2. Full scalar population. Independently enumerate the fixed344 unique IDs,
   group totals, kernel names, API roles, query coordinates and expected
   admission from the specification. Decode integer IEEE bit fields rather
   than trust printed float summaries. Re-derive literal affine and null
   expectations, tiny dispatch endpoint literals, nonfinite refusals, and
   compare with the saved oracle field as well as actual output. Re-evaluate
   actual-versus-paired finite comparisons for translated-stencil and
   must-differ rows with the frozen tolerance. A missing, duplicated,
   out-of-order, changed-coordinate or falsely passed row must fail this
   population review. A genuinely numerical failing row remains a result,
   not a metadata failure that can erase the baseline.

3. Power and coupling. Check the saved actual wrong-translation/wrong-phase
   pairs, restored pairs, raw/clamped cubic values and effective fallback
   endpoint/far-high values. Where complete stored operands suffice, recheck
   the corresponding predicate. Where a reported exercise flag involves
   unsaved tap arrays or changed-input counts, label it a source-bound
   reported witness and do not claim independent reconstruction of that
   runtime observation. Paired Lanczos calls are coupled translation tests;
   they are not independent estimates or absolute first-moment truth. A DC
   pass alone could hide the coordinate defect and is therefore only a null
   and regression control. The limiter hull could hide shared coordinate
   shifts and cannot replace the coordinate criterion.

4. Full gather reconstruction. Decode every one of the12288 row-major
   f32 words and each bit of both saved masks. Derive x/y from the linear
   index and classify by independent integer sets: accepted x1..126,
   y1..94, with the final accepted column, final accepted row and their
   corner separately reported; all other positions are refused. Compute
   requested-map literal truth directly from reference x/y and its quarter
   translation. Require exact mask, finite accepted values within1/32 and
   NaN refusals. Recompute counts and positive/opposite-direction residuals
   without using the test's census fields as input. Preserve all baseline
   discrepancies. This is a different spatial partition from the test's
   worst-error summary; a count-only agreement cannot admit a reversed map.
   The opposite map has the same accepted integer set, so values must
   discriminate it after a successful actual mask/count population.

5. Before/after and scope. Require baseline actual101 plus its complete
   transcript and at least one exercised finite failed public boundary row.
   Do not pre-guess its total failure count. Require repaired actual0,
   all344 passed, and the separately saved exact thirteen named library
   results with none ignored or unexpectedly included. Compare original
   and repaired source map keysets, all unchanged source bytes, and the
   sole allowed align.rs difference against the reviewed candidate and
   archived original. Reclassify scalar changes into boundary, unchecked
   extension/fallback, nonfinite, null and interior categories. A repair
   that drops previously finite covered queries cannot pass merely by
   reducing value mismatches.

### Admission language and remaining limits

This audit can establish fixed software contract behavior and actual result
association. It cannot establish every signal, all arbitrary coordinates,
unchecked NaN safety, nonfinite sample-data behavior, physical geometry,
native CFA conversion, sharpness, quality, performance, a resampler ranking,
a changed default or SOTA. Literal controls establish the claimed property
only on their specified scalar inputs. Deterministic nulls have no estimated
statistical standard error; no noisy-effect ratio or statistical replication
is inferred.
