1Presets and batches. Export is one file at a time today, and its settings reset at every launch. A preset holds format, colour space, size and quality; ticked presets export together through the job tray.
2Size and output sharpening. There is no resize today, so a web copy needs another program.
3What goes into the file is a choice. TIFF export embeds the whole recipe, region names and notes included. That becomes a switch that is off by default; copyright and a scale bar become switches too.
4Export history lives with the photograph. It is in the Projects tree today. Each row says which version made it and whether the file is still the one written, and flags files older than the current version.
