## Findings preserved from the first held draft

1. **The native outer schema is stale.** `native_authority` requires exactly
   five outer fields. The actual `work/native-derivative-1-outer.json` also
   contains `dependency_before`, `dependency_after`, `dependency_error`,
   `dependency_supplement_sha256`, and `admissible_parent_exit`. These are the
   previously reviewed supplemental adjacent-DLL observations. A future
   admitted native result must retain and validate those associations rather
   than strip the fields to satisfy this runner. Native1 itself already fails
   the complete-nine prerequisite and must remain refused regardless.
2. **A partial ordering must not look complete.** The constructor builds its
   `unique` list while hashing/copying the input bundle, before it initializes
   `supports` and `sources`. On failure there, the traceback may expose a
   partial or empty `unique`. The observer currently may report an empty
   unvisited suffix simply because both source and unique counts are zero.
   Record whether the constructor reached the complete ordering, and leave
   the unvisited classification unavailable when it did not. The original
   traceback remains the failure evidence; no resumed solve is needed.
3. **The order destroyer is currently a direction destroyer.**
   `inverse_then(source, anchor)` is the reverse pull, not source composed
   with anchor inverse. The positive literal already tests the reporting
   helper's arithmetic, but the claimed order fault should be literal too.
   For the registered maps, wrong `S composed with A^-1` has linear terms
   `(1/2,-1/2)` and translation `(-4,10)`, versus correct `A^-1 composed
   with S` translation `(-19/5,33/5)`. These are source-level algebraic
   derivations, not new measurements or independent registration accuracy.
4. **Final reported work precedes another full hash pass.** `publish` calls
   full `final_checks` after flushing stdout as well as before it. This
   checks resource limits, but the stdout work snapshot omits that later
   expensive read. Perform the required full closure before constructing
   the summary, then retain a final budget/time check after flush. Root's
   explicit outer carry still owns publication/exit costs. Do not call the
   earlier result work snapshot process-exit accounting.

The author independently identified findings 2 and 4 while these bytes were
held. Findings were sent to author and root before any source revision or
subject execution. No author files were edited by this review.
