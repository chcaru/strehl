# Private grid launch wrapper

Prospective source preparation. This wrapper admits only the fixed generated
grid experiment. No RAW, registered real stack, product default, or quality
claim is released here. All ten plans must precede the component, and all
renders must follow it. The producer's local resource samples are not the
shared campaign authority.

`independent-private-read.py` consumes the externally hashed
`m193c-grid-reader-request-v1`: execution release, build result, actual producer
result and launch, exact Python executable reference, and remaining local
limits. Its exact command is the enclosing release's `commands.grid_reader`
with only `ACTUAL_GRID_REQUEST_SHA256` replaced. Python runs with `-B`.
The reader's executable reference may intentionally be outside the repository;
experiment references and imported source must remain inside it.

Before numeric work, authenticate the common source closure, actual compiler
messages, compiled build stamp, copied executable, producer command and
terminal observation, all ten plan launches, the component launch, and all ten
render launches. Check their recorded exact arguments, sanitized overrides,
actual logs and one-test summaries, terminal zero-active Job accounting and
monotonic sequence. Context is derived from the external build and common
source release, never solely from a subject plan's self-description.

Then execute Curie's unchanged fixed 45 control schedule. Retain the mutable
active child on refusal. Only after those pass, read all ten complete entries
and the entire 3712-sample component. Keep individual case results and precision
in bounded child JSON files. A numerical refusal, absent positive companion,
wrong refusal boundary, failed launch or persistence error prevents
`PASS_GRID_ADAPTER_PRIVATE_ONLY`.

Each JSON or mutant artifact is capped at 4 MiB. The reader receives at most
120 CPU seconds, 240 wall seconds and 32 MiB reserved new artifacts. Its
independent numeric reader retains the 32 MiB tracked-array ceiling. The
512 MiB cumulative input ceiling includes wrapper authority and numeric reads
together, including final rereads; neither stage resets it.
These are operational bounds, not performance measurements. The enclosing
campaign observes the whole process tree against 600 CPU seconds, 1200 wall
seconds and 128 MiB artifacts, including failed attempts and partial files.

Final checks run after the result write. A late failure renames any apparently
successful canonical result before attempting a bounded refused replacement;
both the actual process exit and final result are required. The local work
sample explicitly precedes publication. The outer terminal observation owns
complete process accounting and the overall private-stage admission.
