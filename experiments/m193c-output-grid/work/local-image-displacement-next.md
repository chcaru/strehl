A useful real outcome requires reproducible displacement information from disjoint image evidence, with the displacement sign and source/reference/native gauges explicit. Forward/backward reuse of one correlation peak is not independent corroboration. Patch consistency may still follow repeated texture, defocus or occlusion, so it does not establish physical accuracy.

## Required falsifiers before the real calls

Commission the actual estimator using independently evaluated continuous patterns with nonwrapping integer and fractional translations, differential symmetric blur, unchanged-image placebos, featureless flats, unrelated patches and periodic/multiple-peak distractors. Fix these cases in advance, including a known shift outside the admitted search range. A finite image boundary must not be mistaken for a wrapped displacement. A wrong-sign/map mutation must fail the literal displacement oracle; a periodic or mismatched positive-looking peak must not pass merely because its response is large. Require nonempty successful informative controls alongside explicit refusals.

The private signal must express the proposed failure: an integer-only copy is insufficient for subpixel accuracy; an unchanged sharp image is insufficient for cross-defocus behavior; an artificially blurred same-image pair calibrates that plant only. Response measures peak concentration, not accuracy. A score's failure direction belongs beside its use. Keep the actual input arrays and estimator output hashes identical with observer off/on/placebo, and preserve restored equality. Use an independent verifier with a different defensible choice of reference computation or local estimation, retaining disagreements.

If known controls fail, stop before the real population and name the concrete estimator deficiency. If controls pass but real probes are incoherent or refuse, retain that finite negative result; do not tune the patch grid or threshold. If useful disjoint local evidence survives, the next step is a separately tested local-refinement/direct-edge implementation scored per frame in the merge's named gauge, with curved-track plants as required by M103.
