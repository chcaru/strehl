## The guard work required before any support admission

Owned source `reference.py::register_to_reference` adds1 Q8 to the held-out maximum. `consumer.py::validate_manifest` explicitly requires quantum==1, guard==maximum+quantum and margin==128+guard. A producer cannot relabel an 8-Q8 detector lattice as qualified by merely changing one field: a future support contract/reader must be versioned, and the old v1 assertion must remain intact.

A proposed deterministic rounding contribution can be derived without using real registration as truth. A coarse coordinate is rounded within half a coarse Q8 step, hence each lifted native endpoint coordinate has component uncertainty at most4 Q8. For a fixed native source-to-reference linear map A, transforming the reference endpoint error back into source coordinates gives the conservative component bound:

`q_guard = ceil(4 * (1 + ||A^-1||_infinity))` in native Q8 units.

For Q32 similarity coefficients a,b, the norm is `2^32*(|a|+|b|)/(a*a+b*b)`. This is a proposed rounding-only bound, not an error bar for fitted parameters or extrapolation beyond observed sites. A blanket +8 is inadequate for all scales: a half-scale map has a larger inverse norm. Keep the retained held-out residual contribution and raster-footprint semantics distinct from this rounding term.

Before implementing support admission, independently commission this arithmetic and the actual inverse-support interval consumer on fixed nonidentity maps and all corner signs of the two endpoints' rounding uncertainty. Include identity, exact quarter-turn, half-scale, double-scale and one mixed-axis rational-Q32 similarity. A known too-small bound must fail. Place translated source boundaries within a Q8 step of an integer reference centre so decreasing a guard actually changes whether that centre is valid; otherwise a guard-mutation test may be arithmetically different yet geometrically powerless. Compare the interval consumer against direct Fraction inequalities, including each image edge and a swapped-axis negative. A source-only algebraic inequality is labelled DERIVED until these consumer controls run.

Even a qualified rounding margin does not prove the fitted map is correct outside its landmarks. Absolute-map uncertainty and spatially independent support still need their own qualification. In particular, the charter's1-pixel landmark condition and0.1-pixel product output-map condition are different quantities. Neither becomes coffee-bean ground truth. No step here clears the common-input merge/color/noise prerequisites or any SOTA quality score.

## If the private native oracle fails

First use the saved actual true feature arrays and matched coordinates to score every match against the literal rotation truth, independently of the fitted map. Compare signed residual vectors, true-map inlier count, spatial distribution and the returned map's corner errors. This requires no new image or fitter call and can distinguish a coherent wrong match geometry from a fit that fails despite accurate known correspondences. The existing failure mode, a low fitted RMS with a wrong literal map, must remain a negative example for this analysis.

If the saved evidence does not identify the boundary, the next bounded disambiguating image experiment is a fixed exact-permutation check on the same fixture with explicit true retained: add the exact180° and270° cases to the already-measured90° case, with no interpolation, blur, other fixture, resize factor or threshold change. Freeze both before either runs; retain both outcomes even if one fails. The literal source-to-reference map is independently known for each image shape and rotation, so each has power to reject a coherent detector-coordinate bias that a fitted residual can miss. The prior90° result is the calibration arm only for a proposed common-offset model; predictions for the other two angles are held out. Fit no per-angle correction.

Under a hypothetical common detector offset delta, a rotation R would contribute `(I-R)*delta` to translation. This is a falsifiable model across rotations, not an established mechanism. Feature/descriptor populations may change with the rotation, so a model failure does not isolate blur or prove the absence of an implementation bias. Pair the known-map oracle with an active wrong-map mutation and restoration. If feature support itself refuses, record that distinction; do not invent a successful geometric estimate from the refusal. A matcher-free known-correspondence fitter check is appropriate only if the saved-coordinate analysis specifically points to the fit path.

## Why this does not reopen blur equalisation

M78 already tested Gaussian cross-blur and a bilinear half-shift on short alignment edges. Its primary cross-blur arm moved conservation toward unity while worsening paired held-out prediction; neither arm shipped. SYNTHESIS facts1097–1099 record that outcome. The old SYNTHESIS prose still calling R5 open is superseded by those measured rows, and should not commission a repeat. M78's own blur plant also failed to express its proposed positive mechanism; an instrument control passing was not evidence of that mechanism.

M103's later facts1407–1410 further require per-frame consumer placement, named gauge and nonlinear-track-aware synthetic tests. They correct the endpoint acceptance framing; they do not retrospectively establish Gaussian cross-blur as a successful repair. M78b is a separate held-out ROI-coordinate repair and does not supply a localization treatment. This next program step is therefore the smallest fixed real correspondence diagnostic after the known-map control, followed only by the concrete support/consumer defect its saved evidence names.
