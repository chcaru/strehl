SOURCE ONLY, 2026-09-08. This helper prepares one fixed release; it never imports
or executes the subject/estimator, reads a native TIFF or RAW, or calls a model.
Independent source review and a committed source freeze must precede execution.
A successful preparation is not itself a subject or audit execution release.

Run the selected Python3.12.10 with -B from the repository root, using an
absolute helper path and one --source PATH BYTES SHA256 triple for every held
fresh source/review. Hashes must be lowercase SHA256; byte counts positive.
The embedded REQUIRED list includes the runner, estimator, patch reader,
preregistration, exact output ledger, this helper/recipe, independent subject review, root source
read, independent saved-output checker and independent preparation review.
The actual argv is checked against sys.orig_argv. No hidden interpreter flags,
trial subject import or missing-source fallback is accepted.

The preparer authenticates the fixed completed v3 audit and its actual outer
exit/tail, the old312 positive source bindings and the admitted native TIFF
metadata. Only the fixed pair identities local0/1 and3/4 (original0/13 and39/52)
are selected. Baseline admission and historical complete CPU accounting remain

Every fresh --source addition is counted in the new source allocation.

## Runtime file scope

The runtime map is a deterministic file walk of the selected interpreter's Lib
(excluding its site-packages subtree), DLLs, and the numpy/scipy/skimage/
lazy_loader/packaging/imageio/PIL package directories. Only .py and .pyd files
are included. Directories named site-packages, __pycache__, tests and test are
pruned. Each package root is separately visited, so the site-packages pruning
does not skip selected packages. No imports are used for discovery and no .pyc
or diagnostic outputs are written during preparation.

Positive external files use runtime_bindings. Legitimate zero-byte Python
initializers have a separate runtime_empty_bindings map requiring integer0 and
the canonical empty SHA256. Sources remain strictly positive; overlapping roles,
boolean zero and false empty hashes are rejected. Three preparation-only
metadata corruptions must reject before release; the restored namespace must
pass. The worker separately checks actual imported module files and aliases
against the prepared namespaces. An undeclared import is a refusal, not a reason
to expand the map mid-run. Native dependent DLL completeness, package provenance
beyond the named files, and parameter state are not asserted by this inventory.

Read-only inventory before implementation found2,087 positive files totaling
127,531,108 bytes, with an estimated437,627 bytes of serialized bindings. This
estimate was not a prepared hash map and excludes the empty entries. The real
preparer must independently enumerate/hash its exact bounded population and
