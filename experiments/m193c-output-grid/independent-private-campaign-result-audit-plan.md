# M193c prospective independent terminal-result audit

This is a read-only audit plan for the first released private campaign. It is
not a new image population, numerical criterion, process execution release, or
private-stage admission. The deciding limits and populations remain those of
the held campaign specification. Wait for root's actual terminal notification;
absent or unfinished files before then are not a failure observation.

1. Bind the actual release, committed source revision, literal command, runtime,
   and source/input maps. Rehash the release, current released files and retained
   snapshots where declared. Distinguish current bytes from historical source
   revisions. Attribute the original outer OS exit and launch-session observation
   to root; independently inspect the retained stdout receipt and its actual
   result/index/gate references. Do not claim to have waited on an OS process
   that this reviewer did not launch.

2. Reconstruct owner-to-worker and all four actual stages from observations and
   logs. Check exact commands, request hash substitutions, named test and summary
   where required, actual log hashes/extents, zero exits, terminal Job accounting,
   active-process counts and cleanup errors. Check adjacent retained intervals
   and the grid wrapper's actual ten-plan/precision/ten-render chain. Interpret a
   failed stage and its unvisited suffix as an incomplete private population;
   inspect retained failure evidence rather than admitting a successful subset.

3. Independently form CPU as the encompassing Job's terminal user+kernel CPU plus
   owner CPU, exactly once. Compare the stored prepublication work with the
   separately retained final stdout work. Do not add worker or nested stage CPU
   again. Check actual 600 CPU/1,200 wall limits, the Job's committed-memory
   setting/observation and the complete 128 MiB artifact inventory. Keep observed
   per-path high-water space, retained size, wall scope, and RSS distinct.

4. Inspect every grid deciding record: 45 unique controls with the required
   35-refusal/ten-companion partition, ten literal case identities and all 3,712
   retained precision observations with their liveness and fixed predicates.
   Bind each plan/receipt/TIFF and the precision witness to the actual producer
   records and launches. Preserve the distinct source and independent reader
   roles. No author helper import and no recomputation of its numerical operator.

5. Inspect all 32 source and 41 independent derivative control records, exact
   IDs/order/pass fields, actual source-record association, two output references,
   `[22,30,3]` dimensions, 54/660 compared sites and the unchanged one-code bound.
   Trace the normalized request paths with exact hashes/extents, rather than
   relying on textual equality between absolute and repository-relative paths.

6. Enumerate the ten grid plus two derivative product files. Rehash actual file
   bytes, check twelve distinct native file identities, and compare the complete
   producer-directory TIFF set with that population. Keep reader mutation files
   separate while including them in artifact space. Independently reconstruct
   the uncompressed classic-TIFF strip bytes using ordinary byte reads, without
   importing either subject reader, and compare actual dimensions/sample tags
   and little-endian u16 pixel digests against the independent reader records.
   Bound each read by the existing small output-file contract. An unsupported
   layout is an audit limitation/refusal, not permission to reinterpret bytes.

7. Reopen the final canonical result, derivative gate and artifact index; compare
   their final hashes with root's actual stdout receipt. Check errors, secondary
   errors, retained first/refused versions and completed source/input closures.
   A positive file without the actual zero exit and matching final receipt does
   not establish admission. Report any consequential mismatch before final claims.

Only after actual terminal inspection should a separate measured review name
the result/release hashes, observed resource scope and complete or incomplete
population. Successful private synthetic commissioning cannot establish native
RAW decode, registration coverage, physical calibration or image quality.
