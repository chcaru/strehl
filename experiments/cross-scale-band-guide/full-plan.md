Native pass1 folds the canonical merge in the original chunk association and
sends each source's actual cached AC coefficients to one persistent Torch child.
The child accumulates sequential f32 sums/squares exactly as the commissioned
generic consumer. It retains only O(image) source statistics. After all70
sources it converts them to the same mean/scene-SD/scale context. Scene SD is
not an injected-noise estimate. No statistics are inferred privately from flat
or background samples.

Pass2 re-decodes originals and checks actual gathered planes, guide, variance,
beta, coefficients and canonical fields against pass1. Native computes exactly
the exporter's five inputs: log1p(E/max(F,1)), log1p(F), Gaussian G/range,
Gaussian(R-G)/range and Gaussian(B-G)/range. The child uses unchanged generic
source_features and score_source, including actual parent/child expansion,
validity flags, full-domain scales and256px tiles with3px network context.
Positive weights in(0,2] return to native add_fields. One source transaction is
live at a time. There is no N-source feature/coefficient/activation cache.

Binary pipes carry bounded u32-length JSON headers and declared LE-f32 arrays.
Stats must arrive0..69, then exactly the declared scoring order. Shape/count,
nonfinite payload and invalid output weights refuse. Any error kills and waits
for the owned child; the external bounded job also owns the process tree.
No fallback model, uniform rescue or package installation is permitted.

Cost mode still collects all70 real contexts and writes the complete canonical
baseline, but scores only source35. It prices feature construction, pipe/CUDA
scoring and actual add_fields with the real context. It emits no partial
candidate image or quality claim. Full mode scores all70 and writes the complete

tone. Historical RGB differences due solely to automatic tone are disclosed:
