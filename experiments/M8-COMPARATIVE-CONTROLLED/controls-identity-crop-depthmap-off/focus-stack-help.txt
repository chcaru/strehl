Image merge options:
  --consistency=2               Neighbour pixel consistency filter level 0..2 (default 2)
  --denoise=bayesshrink         Wavelet denoise mode (default bayesshrink). Allowed:
                                  bayesshrink  per-subband adaptive soft-threshold (Chang/Yu/Vetterli 2000;
                                               sigma_noise estimated via MAD of the merged finest HH band)
                                  fixed        legacy fixed-lambda |c|^2 soft-threshold (matches pre-Phase-2)
                                  off          skip denoise entirely (pass-through; for debugging)
                                  <float>      legacy compatibility: same as `fixed` at that level
                                               (e.g. --denoise=1.0 == --denoise=fixed; --denoise=0 == --denoise=off)
  --reassign=winner-copy        Color-output mode: winner-copy (default), guided-blend, legacy.
                                winner-copy copies BGR from the per-pixel winning source frame
                                (full-res argmin of |gray_k - merged_gray|). guided-blend computes
                                per-frame saliency, smooths it with a guided filter, and produces
                                a soft weighted average of source colors. legacy keeps the old
                                grayscale-distance Task_Reassign path (slower; can produce halos).
  --guided-radius=8             Guided-filter radius for --reassign=guided-blend (default 8)
  --guided-eps=0.01             Guided-filter epsilon for --reassign=guided-blend (default 0.01)
  --winner-smooth=3             Box-filter kernel applied to each per-frame |gray_k - merged_gray|
                                distance map prior to the per-pixel argmin in winner-copy mode.
                                Suppresses isolated single-pixel winner flips at marginal edges
                                (frames nearly tied). Allowed values: 0 (disable), 3 (default), 5
                                (heavier; very slightly softer fine boundaries).
  --compose-mode=winner         Top-level color-compose dispatch (Phase 12.4 Pick-5-swap):
                                winner (default) routes to --reassign={winner-copy,guided-blend,legacy};
                                mertens replaces the entire compose path with multi-scale Laplacian-
                                pyramid fusion (Burt-Adelson 1983 / Mertens-Kautz-Van Reeth 2007).
                                Mertens fuses low-frequency cleanness from the cleanest frames with
                                high-frequency detail from the sharpest frames simultaneously, with
                                no halo / seam artefacts at the focused / defocused boundary. When
                                set to mertens, --reassign and the Phase 8.2 / 9.1 / 11.7.3 cross-
                                frame-mean overrides do not apply (the pyramid IS the fuse), and
                                --cross-frame-denoise is auto-suppressed (Mertens already averages
                                across frames).
  --mertens-levels=auto         Pyramid depth for --compose-mode=mertens. auto (default) =
                                clamp(floor(log2(min(rows,cols))) - 2, 3, 8); on a 32 MP frame
                                that resolves to 8. Override with an integer in [3, 10] to test
                                shallower (faster, less low-frequency separation) or deeper
                                (slower, more aggressive low-frequency averaging).
  --mertens-weights=confidence  Per-frame weight strategy for --compose-mode=mertens.
                                  confidence (default): argmax-frame gets weight = depth_confidence(p),
                                                       remaining frames split (1 - confidence) / (N-1).
                                                       Falls back to saliency when no depthmap is wired.
                                  saliency:   per-frame |Laplacian(gray_k)|, normalised across frames.
                                  equal:      uniform 1/N. Pure pyramid average. Debug baseline.
  --blend-sharpness=16          Wavelet-coefficient merge mode (default 16 = softmax blend).
                                Activates softmax blend:
                                    w_k = exp(beta * (|c_k|^2 / max_k|c_k|^2 - 1))
                                    c_out = (sum_k w_k * c_k) / (sum_k w_k)
                                Smaller beta = softer blend, larger = sharper / more WTA-like.
                                Typical useful range: 4..32. Reduces 'which frame won' edge
                                speckle when two frames have near-tied |c|^2 (no measurable
                                detail loss for beta >= 8 on macro stacks).
                                The shipped default of 16 measurably improves edge speckle vs
                                pure WTA (closer to the v3 reference on every metric we track).
                                Set --blend-sharpness=inf for the legacy WTA pre-Phase-2 behaviour
                                (also reachable via --legacy-merge-wta, which is bit-identical to
                                pre-P2.1 builds when paired with the other --legacy-* flags).
  --align-residual-weight=on    Phase-2 P2.6 per-pixel alignment-residual soft weighting in merge
                                (default on). Each frame's wavelet contribution is multiplied by
                                a per-pixel reliability weight W_k(x,y) derived from a high-pass
                                of |I_k_aligned - I_ref| (smoothed at ~8 px, baseline subtracted
                                at ~32 px to discount focus-blur differences). W_k is in (0, 1];
                                pixels with residual much larger than the robust scale get heavily
                                down-weighted. Removes 'two-edges-add' ghosting in regions where
                                affine alignment couldn't capture local breathing / parallax.
                                Set =off (or use --legacy-merge-weights) for a bit-identical
                                pre-P2.6 binary.
  --align-residual-sigma=auto   Robust scale for the residual-to-weight mapping (default auto).
                                'auto' uses 1.4826 x MAD(R) per frame (in 16-bit grayscale units,
                                0..65535). A fixed float overrides — smaller = more aggressive
                                down-weighting.
  --legacy-merge-weights        Alias for --align-residual-weight=off (legacy bit-identical merge).

Depth map generation options:
  --depthmap-threshold=10       Threshold to accept depth points (0-255, default 10)
  --depthmap-smooth-xy=20       Smoothing of depthmap in X and Y directions (default 20)
  --depthmap-smooth-z=40        Smoothing of depthmap in Z direction (default 40)
  --focus-measure=wavs          Per-frame focus measure that drives the depthmap (default wavs):
                                  wavs       Multi-scale Wavelet Activity Value Sum -- reuses the
                                             per-frame complex Daubechies pyramid already computed
                                             by the merge stage (no extra DWT pass). For each of
                                             the 4 finest pyramid levels L=0..3, sums |c|^2 across
                                             the HL/LH/HH detail subbands, bilinearly upsamples to
                                             full resolution, weights by 1/2^L (level 0 finest),
                                             accumulates, and takes sqrt. Captures focus at multiple
                                             spatial frequencies; less spike-prone than the single-
                                             scale Sobel, yielding a ~50x smoother depthmap with
                                             wider dynamic range. Coarser levels (L>=4) are skipped
                                             because each coefficient there spans 32+ full-res
                                             pixels and pollutes the per-pixel noise floor used by
                                             the depthmap Gaussian fit.
                                  tenengrad  Legacy single-scale Sobel |grad|^2 (bit-identical
                                             to pre-Phase-2.2 builds).
  --depthmap-inpaint=guided     Depthmap polish mode (default guided):
                                  guided  -- guided filter on the depthmap with the merged
                                             AIF luminance as edge guide (He et al. 2010).
                                             Smoother in flat regions and better aligned to
                                             real subject edges than the legacy chain.
                                  legacy  -- median + bilateral + median (matches pre-Phase-2).
                                  tv      -- Phase 11.7.1 confidence-weighted Poisson/TV
                                             relaxation. Replaces the polish stage with a
                                             Jacobi sweep driving u_new = (w*d + lambda*Lap(u))
                                             / (w + 4*lambda); w is the Phase 8.6 fused
                                             confidence map (CV_32F [0,1]), so high-confidence
                                             pixels stay anchored to the raw depthmap d and
                                             low-confidence pixels fill from neighbours. With
                                             --confidence-mask=off it degenerates to a weighted
                                             smoothing pass biased toward d everywhere.
  --depthmap-inpaint-lambda=0.5 Smoothness weight for --depthmap-inpaint=tv (range 1e-4..10,
                                default 0.5). Higher = smoother / more neighbour-driven; lower
                                = more fidelity-driven.
  --depthmap-inpaint-iters=150  Jacobi sweep count for --depthmap-inpaint=tv (range 1..1000,
                                default 150). More iterations = closer to the variational
                                minimum; cost is linear in iters.
  --depthmap-guided-radius=20   Guided filter radius for --depthmap-inpaint=guided (default 20).
                                Wider than the compose path's --guided-radius=8 to roughly
                                match the legacy bilateral's 41-px diameter (the depthmap
                                signal is smoother than the color signal so wide windows
                                don't blur structure -- they just denoise more).
  --depthmap-guided-eps=1e-2    Guided filter epsilon for --depthmap-inpaint=guided (default 1e-2).
                                Same magnitude as the compose path's --guided-eps. The AIF
                                guide carries paper-grain / marker-fiber micro-texture; a
                                smaller eps (e.g. 1e-4) transfers that texture into the
                                depthmap. 1e-2 preserves macro subject boundaries while
                                ignoring guide micro-texture.
  --remove-bg=0                 Positive value removes black background, negative white
  --halo-radius=20              Radius of halo effects to remove from depthmap
  --3dviewpoint=x:y:z:zscale    Viewpoint for 3D view (default 1:1:1:2)

                                consistency) geometric-mean-fused into a scalar [0,1] confidence

                                Task_Depthmap::mask(), which the depthmap-inpaint stage consumes.
                                Default on. Largest depthmap-quality win on smooth substrate /
                                bokeh / deep shadow next to sharp edges (texture channel zeroes
                                confidence so inpaint fills from spatial neighbours rather than
                                propagating wrong depth from far-away edges). =off reverts to
                                Phase 8.5 hard mask (or legacy when --cross-scale-mask=off).
  --depthmap-chain=auto         Phase-12.5 gate whether the Task_Depthmap chain runs even
                                when no --depthmap PNG / --3dview is requested. Pre-12.5 the
                                chain was gated on PNG output only, which meant the entire
                                confidence pipeline (P8.6 mask, P9.1 confidence-color-blend,
                                P9.8 Helmli-Scherer, P11.2.3 cross-channel, P12.x DA2)
                                silently no-opped at default flags because the per-pixel
                                confidence vector was never computed. auto (default) = on
                                when --confidence-mask=on AND --reassign!=legacy. on =
                                always run the chain. off = restore pre-12.5 fast path
                                (bit-identical to pre-12.5 default-flags output). Cost:
                                ~+45 s wall on a 33-frame 32 MP stack; pays for ~3.6% mean
                                SMOOTH-region noise drop (96% of ROIs improved vs pre-12.5).
  --confidence-color-blend=auto Phase-9.1 route the P8.6 confidence map into the color compose
                                path. auto = on when --confidence-mask=on (default), off
                                otherwise. Pixels with depth confidence < threshold get the
                                cross-frame mean color (same override Phase 8.2 flat-noise merge
                                produces; the two masks are OR-ed). Distinct trigger: 8.2 gates
                                on cross-frame gray variance (flat regions); 9.1 gates on depth
                                confidence (ambiguous-depth halo annulus around occlusion edges,
                                where gray variance is HIGH but the chosen winner is unreliable).
                                =off is bit-identical to Phase 8.2 output.
  --confidence-color-threshold=0.20
                                Threshold beta in [0,1] for --confidence-color-blend. Lower =
                                more conservative (fewer pixels overridden). Typical 0.15..0.30.
  --confidence-color-softblend=off
                                Phase-12.6 confidence-weighted soft blend. When on, replaces the
                                Phase 9.1 binary low-conf gate with a linear ramp of width
                                --confidence-color-softband BELOW the threshold. Pixels with
                                confidence >= T are untouched; pixels with confidence <= T-B get
                                the full cross-frame mean (same as binary); in between, a partial
                                blend. Phase 8.2 flat-mask pixels still get full replacement.
                                =off is bit-identical to Phase 9.1 binary path.
  --confidence-color-softband=0.10
                                Width B of the soft-blend ramp (0 < B <= 0.5). Used only when
                                --confidence-color-softblend=on.
  --temporal-fm-filter=off      Phase-9.4 N-tap centered median filter of the per-frame focus
                                measure across frame index (delay = (N-1)/2 frames). Applied
                                per-pixel BEFORE Task_Depthmap's add_to_guo / per-scale argmax
                                update -- eliminates single-frame focus-measure spikes from
                                motion blur or exposure jumps that would otherwise pull Guo's
                                Gaussian-fit mean off the true peak. Edge-clipped windows at
                                the bracket endpoints (3, 4, then 5 taps on entry; mirror on
                                exit). Off by default: spike-free brackets (the marker test
                                set) gain nothing from the smoothing. Modes:
                                  off      no filter (default; bit-identical to pre-9.4).
                                  median3  3-tap centered median (1-frame delay).
                                  median5  5-tap centered median (2-frame delay).
  --robust-guo=off              Phase-9.3 Robust Guo via IRLS (Tier 2.7): two-pass Gaussian fit.
                                Pass 1 = the existing Guo closed-form Hankel solve. Pass 2 =
                                Cauchy-weighted re-fit. Per-pixel, computes residuals
                                r_x = y_x - A*exp(-(x-mu)^2/(2*sigma^2)) against the pass-1
                                fit, derives a robust scale s = 1.4826 * MAD(r), then weights
                                w_x = (1 + (r_x/s)^2 / 2.385)^-1 (Cauchy psi-function tuning
                                constant k=2.385), and re-accumulates m_guo with each frame's
                                contribution multiplied by w_x. The closed-form Hankel solve
                                is unchanged. Eliminates motion-blur / exposure-spike-frame
                                domination of the Gaussian fit. ~3-5 s extra wall time and
                                ~8 GB transient RAM on a 33-frame 32 MP bracket (per-frame
                                y_nobias buffer + residuals). off (default) is bit-identical
                                to pre-9.3 output.
  --helmli-scherer-channel=auto Phase-9.8 6th confidence channel (Tier 2.13): Helmli-Scherer
                                ratio HS(p)=max(M/mu, mu/M) on a 7x7 window of each frame's
                                grayscale, running-maxed across the bracket, normalised by
                                p95 and folded into the geometric-mean confidence fuse as
                                channel f. Different failure mode from WAVS: WAVS responds
                                to high-frequency content (blind on textureless smooth-
                                gradient regions); HS responds to local contrast (blind on
                                high-frequency). Combining them cuts smooth-region depth
                                fizz where WAVS alone returns noise. ~2.6 s extra wall time
                                on a 33-frame 32 MP bracket. auto = on when --confidence-
                                mask=on (default); off is bit-identical to pre-9.8 (4- or
                                5-channel fuse depending on cross-scale-mask).
  --cross-channel-channel=auto  Phase-11.2.3 7th confidence channel: per-channel Laplacian-
                                variance focus measure on the aligned color image (B, G, R
                                separately) with a per-pixel per-channel running argmax across
                                the bracket. At depthmap finalisation the cross-channel
                                agreement count -- number of channels (1..3) whose argmax is
                                within +/-1 frame of the median of the three -- is normalised
                                by 3 and folded into the geometric-mean confidence fuse as
                                channel h. Catches axial CA, halo annulus and color-fringe
                                edges where the three color channels see slightly different
                                in-focus frames even though luma is unambiguous -- a failure
                                mode the luma-based WAVS / Helmli-Scherer channels miss.
                                ~10-15 s extra wall time on a 33-frame 32 MP bracket. auto
                                = on when --confidence-mask=on (default); off is bit-
                                identical to pre-11.2.3 output.
  --cross-frame-denoise=off     Phase-10.1 cross-frame patch denoise via OpenCV's
                                cv::fastNlMeansDenoisingColoredMulti, scheduled AFTER
                                Task_Compose_Color and gated on the Phase 8.2 + 9.1 union
                                override mask. Replaces the cross-frame arithmetic mean
                                substitution with a patch-similarity-weighted denoise that
                                exploits non-local self-similarity across the bracket.
                                Modes:
                                  off      no scheduling (default; bit-identical to pre-10.1).
                                  light    h=10, hColor=10, template=7, search=21, T=5.
                                  strong   h=15, hColor=15, template=9, search=27, T=7
                                           (~50%% more wall time).
                                Wall-time cost: ~60-130 s on a 33-frame 32 MP bracket
                                (CPU-only — OpenCV's Multi NLM lacks an OpenCL kernel).
                                HDR-preserve path keeps any pixel with channel > 1.0
                                verbatim from compose (the 8-bit NLM can't represent
                                overshoot above 1.0).
  --per-frame-denoise=off       Phase-12.8 per-frame single-image NLM denoise inserted
                                BETWEEN Task_Align and Task_Compose_Color. Targets the
                                in-focus pinch zone (~15%% of image) that is verbatim
                                single-frame-copy and therefore carries 1x per-frame
                                shot noise -- the only zone NOT already cleaned up by
                                Phase 8.2 (cross-frame mean of flat regions) or Phase
                                9.1 (confidence-blend low-confidence regions). The
                                grayscale chain (focus measure / wavelet / depthmap /
                                Phase 11.7.3 lucky imaging) keeps reading the UN-
                                denoised aligned grayscale so WAVS peaks and Guo
                                Gaussian fits are preserved.
                                Modes:
                                  off        no scheduling (default; bit-identical to pre-12.8).
                                  nlm-light  h=6,  hColor=6,  template=7, search=21 (+25-40 s).
                                  nlm-strong h=10, hColor=10, template=9, search=27 (+60-80 s).
                                HDR-preserve path keeps any pixel with channel > 1.0
                                verbatim from the aligned HDR companion (NLM uint8 quantises
                                overshoot above 1.0).
  --per-frame-denoise-vst=auto  Phase-12.9 Anscombe variance-stabilising transform wrap
                                around --per-frame-denoise. When on, the linear-light HDR
                                companion is routed through apply_anscombe -> uint8 NLM
                                (h_vst=102 light / 178 strong, vst_scale=51) -> inverse_
                                anscombe before being re-encoded for compose. Stabilises
                                Poisson-Gaussian noise to (near-)intensity-uniform sigma
                                so a single h is optimal across the whole intensity range,
                                where the Phase 12.8 constant-h NLM over-smooths shadows
                                and under-smooths highlights. Values:
                                  off   never wrap with Anscombe (Phase 12.8 path).
                                  auto  (default) on iff --per-frame-denoise != off AND
                                        the loaded noise profile's source starts with
                                        'preset:raw_' (raw-domain calibrated). The shipped
                                        presets/noise_profile.json is 'preset:iso_50' so
                                        auto resolves to off there.
                                  on    force VST regardless of profile source (logs a
                                        verbose warning when source is not raw-domain;
                                        Anscombe with a near-zero shot-noise slope is
                                        degenerate and over-denoises).
                                Has no effect when --per-frame-denoise=off. Off-VST path
                                is bit-identical to Phase 12.8.
  --match-residual-confidence=auto
                                Phase-11.2.4 per-frame quality weight from Task_Align's
                                match_contrast() post-fit residual RMS. q_i = exp(-(r_i/
                                sigma_ref)^2), with sigma_ref = bracket-median residual.
                                Plumbed to (a) the depthmap Guo accumulator (multiplies
                                each frame's contribution by q_i; composes with --robust-guo
                                Cauchy weight when both are on), and (b) Task_Denoise_Multi
                                window selection (low-q frames inside the NLM temporal
                                window are replaced by the nearest higher-q neighbour
                                outside the window).
                                Values: auto (default; resolves to on), on, off. Off path
                                is bit-identical to pre-11.2.4 output.
  --match-residual-threshold=0.1
                                Phase-11.2.4 NLM window-substitution threshold. Frames
                                with q_i < threshold are excluded from the NLM temporal
                                window. Range [0, 1]; default 0.1. Has no effect on the
                                Guo accumulator (which weights every frame, never excludes
                                any).
  --defect-map=auto             Phase-12.1d cross-bracket defective-pixel map (consensus
                                across N frames). Aggregates per-pixel statistics across
                                every aligned grayscale frame; flags pixels whose value
                                deviates from the per-pixel bracket median by > kσ in
                                >= T%% of frames. Folds into the Phase 8.6 m_confidence
                                (zero confidence at defective pixels -> Phase 9.1 color
                                compose substitutes cross-frame mean) AND into
                                Task_Depthmap::mask() (depthmap-inpaint replaces with
                                neighbour depth). auto = on when --confidence-mask=on
                                (default); off is bit-identical to pre-12.1d. Cost:
                                ~2-5 s on a 33-frame 32 MP bracket.
  --defect-sigma=4.0            Phase-12.1d per-pixel kσ threshold for the 'frame i
                                disagrees with bracket median' predicate, where
                                σ_bracket = 1.4826 * MAD_across_frames + epsilon (epsilon
                                ~ 1 LSB to prevent the σ=0 collapse on flat pixels).
                                Smaller = more aggressive (more pixels flagged). Typical
                                3.0..6.0.
  --defect-fraction=0.70        Phase-12.1d fraction in [0, 1] of frames a pixel must

                                aggressive. Typical 0.50..0.90.
  --da2-prior=off               Phase-12.x DepthAnything V2-Small monocular depth prior
                                folded into the Phase 8.6 confidence vector as channel `i`.
                                Spawns a Python sidecar (scripts/da2_inference.py) on the

                                resizes the output to the aligned-frame size and runs an
                                LSQ linear regression of d_pipeline ~ slope * d_da2 +
                                intercept on high-confidence pixels (Phase 8.6 channel a
                                > 0.5). When slope > 0 and Pearson |r| >= --da2-prior-
                                min-correlation, channel i = exp(-(d_pipeline -

  --da2-prior-python=python     Phase-12.x Python interpreter to spawn the sidecar with.

  --da2-prior-cache=<path>      Phase-12.x DA2 prior cache file (raw int32 header +

  --da2-prior-sigma=0.05        Phase-12.x channel-i Gaussian sigma as a fraction of the

  --da2-prior-min-correlation=0.20

  --lucky-imaging=off           Phase-11.7.3 lucky-imaging tie-breaker for the compose
                                argmin winner. Per pixel: compute local sharpness S_k =
                                7x7 boxFilter(Laplacian(gray_k)^2) for every source frame.
                                For each pixel that is NOT in the P8.2+P9.1 cross-frame-
                                mean union override mask AND has depth confidence >= 0.5,
                                examine a [k* - W/2 .. k* + W/2] window in depth-chain
                                order around the argmin winner k*; if the sharpest frame

  --motion-blur-detect=auto     Phase-11.7.2 per-frame cepstrum motion-blur detector.

                                emits a stderr 'motion-blur warning:' line when the

                                  on        detector active.

  --tonemap=off                 Phase-11.5.1 SDR tone-mapping output op. Compresses HDR
