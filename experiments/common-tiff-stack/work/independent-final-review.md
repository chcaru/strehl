## Re-chosen interpretations

**Contribution instead of a frame counter.** Cases 0–5 each retain three ordered
consumed identities and three immutable actual fold receipts. More decisively,
the independent constant oracle checks every output sample against literal
RGB (17000,23000,29000); none of the three contributors has those codes. That
rejects copying a selected input, while distinct contributor/prefix checks and
their omission/duplication controls cover an identity defect a count alone would
miss. The literal oracle covers 36,864 channel samples. This is fixed-fixture
integration evidence, not a demonstration that every frame contributes useful
detail on a real focus stack.

**Per-level and per-fold support instead of a pooled total.** The preregistered
gate bar uses the final noisy observation pooled across Laplacian levels.
I additionally inspected every Laplacian level after every actual fold. Every
one of the nine observations contains both zero and positive accumulated
selection denominators:

this bar pass. These observations describe accumulated shared denominators,
not each frame's individual threshold decision, the spatial locations of newly
admitted sites, or a correct choice of sharp pixels. Pooling could conceal a
missing branch at one level; these retained observations do not have that defect.

**Literal address/color preservation instead of reconstruction quality.**
Cases 1 and 2 each pass 36,864 literal channel samples and the saved
prequantization hash check. The asymmetric grid and distinct channel/witness
values reject a one-pixel move, red/blue swap and an extra transfer curve.

the original codes, so this result does not establish unrestricted pyramid
reconstruction or stacking quality on different focus planes. A copied frame
would pass these identical-input controls; the separate nonidentical constant
contributors supply the complementary evidence.

result establishes an arbitrary RAW converter's color or noise semantics.
The retained fork's PROPHOTO_DISPROVED verdict is unchanged.
