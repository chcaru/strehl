## Structured visibility: a concrete representation, but a later research lane

If actual insect evidence isolates mutual occlusion, use a **depth-ordered graph of continuous ribbons and closed contours**, rather than one independently optimized opacity per native pixel. Each thin element has a cubic B-spline centerline, continuously varying positive width, explicit end caps, and a depth/disparity parameter or low-order depth variation. Broad scale/petal surfaces use closed spline contours with the same representation. A foreground hair can be0.3native pixels wide without forcing the entire alpha image to be smooth. Two crossing elements retain separate depths and radiance support; their union in image coordinates must not collapse their ordering. Keep full-resolution radiance sheets independent of the geometric knot spacing.

The observation must evaluate depth-ordered visibility on **shared pupil rays and the same sensor-footprint subpoints before averaging**. Merely rendering one native alpha image, bilinearly sampling it, and multiplying marginal near/far coverages loses the subpixel crossing correlation the representation is meant to preserve. The retained pupil code aggregates products of bilinear lattice weights; it cannot be assumed exact for new curve intersections. Reuse its source/CFA geometry and noise likelihood, but commission the changed visibility operator explicitly. Do not call the existing circular pupil, common PSF or supplied two-depth trajectory a calibrated physical model of this rig.

The earliest non-null failure input should be two opaque0.3–0.7native-pixel hairs of different colors at different depths, crossing between sensel centers, observed at several subpixel phases and focus positions. Compare the complete small reconstruction to independent dense ray/footprint truth. Wrong front/back order must fail; a no-hair colored sparkle must not acquire a ribbon; an equal-color constant scene must leave geometry unidentified. Then add a translucent hair as an explicit model-mismatch refusal: fractional footprint coverage is not material transmittance. Hard opaque geometry removes some old alpha freedoms by assumption, not by newly observed data. The exact old alpha/radiance gauge remains a useful warning against interpreting latent magnitudes, even when its transformed masks fall outside this narrower model.

A plausible automatic initialization is to propose repeated paired edges/ridges from multiple original-CFA source neighborhoods, link them across focus only when both green phases support the same geometry, and fit continuous curve/depth parameters jointly to held-focus predictions. It must retain multiple crossing hypotheses, include a no-element option, and allow creation/removal/splitting; starting from a single thresholded focus map would lock in the topology the solver is meant to discover. This initialization and topology search are substantial unsolved work. Tiled radiance and sparse curve storage can bound memory, but do not establish acceptable full-image runtime. Rendering every source/pupil ray/latent sheet at every optimizer step is not presently priced or qualified.

Thus there is a conceptual path to an automatic full photograph, but no short, implemented path comparable to the existing native placement consumer. A constrained local proof would still need every original source, full-image reconstruction, matched development and all hair/scale/halo witnesses before claiming a gain. Under the user's current insect urgency, this lane should not displace the source-to-output intervention.

## Follow-up: baseline-green residual gather algebra

Root proposed preserving baseline MHC-then-cubic green exactly, with each R/B pull reconstructed as `G(query) + I_C[C(s)-G(s)]`, where `I_C` is same-color cubic interpolation over actual C sensels. **DERIVED:** this is distinct from baseline MHC R/B followed by full-grid cubic, not an algebraic reordering. At an interior integer G1 query `(1,0)`, put a unit R impulse at `(0,0)` and zero elsewhere. Baseline MHC R is1/2. MHC G at the query is0. At same-row R sites x=`[-2,0,2,4]`, the residual is `[1/8,1/2,1/8,0]`; half-grid cubic weights are `[-1,9,9,-1]/16`, giving11/32. This counterexample uses the actual `F_G` and `F_H` stencils, not an executed fixture. Both operators still preserve the measured C value at its own integer site. The residual stencil has different and wider raw support.

This operator can reduce that particular red impulse spill, but an isolated real red/blue feature can also be attenuated. Baseline-green preservation avoids the failed QG substitution and preserves the green-driven focus guide. It also means it cannot repair an established baseline camera-green detail loss. Any apparent scale improvement could be chromatic-edge cleanup rather than recovered luminance structure; no prediction of its size is justified before the source witnesses. M95's unchanged-green final color-difference result was visually slight, although it is a different consumer.

Two conditions are easy to miss: evaluate `G(query)` at each color's own CA-composed source coordinate, not at the different green pull, and transport covariance because the guide and residual contain shared raw samples. Adding their variances as independent terms is wrong. Neutral high-frequency input, weak R/B-only structure, clipped single-color sparkle, flat noise and phase sweeps would be the first bounded controls if the actual photograph identifies color spill as the relevant defect. No implementation or test of this proposal was performed here.
