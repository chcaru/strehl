## Exact arithmetic and addressing

Reuse the prior 2,304 old scalar writeback comparisons, preserving their literal buffer oracle and existing assertions. A feature-gated observer compares direct rounded planes to the old scalar u16 buffer followed by black subtraction and nonnegative clamp. It runs within the fixture's 1/2/8-thread pools for both serial/parallel execution choices, each CFA phase, four layouts, all/none/partial coverage, fractional/negative/high black and nonunit inverse WB. Whole and compact crops each compare every consumed f32 bit; output guards remain untouched and full-grid coverage count must survive cropping. Original old-buffer checks still assert untouched padding and odd tails. Their wrong-stride, wrong-phase and flipped-coverage destroyers remain live rather than replacing the original test.

Twenty-four independently specified scalar cases anchor IEEE behavior: infinities, both NaN signs, signed zero, half-integer rounding, low/high saturation, negative/fractional/out-of-range black, nonunit/zero inverse WB, and uncovered rounded-black residues. Additional crossed fault cases compare the old arithmetic for rounded and a separately expressed sensor-clipped continuous policy for float. These invalid metadata cases test exact control semantics, not camera calibration. A covered NaN must still have the old saturating-cast zero behavior before subtracting black. An uncovered black of 0.5 produces 0.5, and uncovered 512.75 produces 0.25: substituting zero is a live failure.

The precision arm must retain `(value*inv+black)-black` in f32, including cancellation. A literal input 2^-16 with black512.25 loses that increment during the addition and yields zero; simplifying directly to `value*inv` would fail. Input1 with inverse WB1.3 and black512.25 yields float1.29998779296875, not the pre-addition product, while rounded yields1.75. Fractional positive examples require the arm to change; an always-rounded implementation cannot pass. The shifted-crop destroyer preserves source values and coverage but must change addressed output.

## Actual gather, probe and writer path

The existing 144 full-resolution RGB/green fixture cases now additionally compare rounded direct output against the actual legacy RGB remosaic/extract result. These retain all six resamplers, tiny/padded/odd layouts, two WB settings and identity/partial/absent-coverage warps. The four-colour full output and two-green compact crop use the same original full geometry. Every direct call must preserve the complete original u16 source buffer, including inactive storage. The existing source-R/B impulse and WB controls establish that the source is not silently reduced to a green-only mosaic.

A separate actual bilinear fractional transform on the existing M194c four-colour fixture requires more than one plane's worth of changed float sites, nonnegative finite outputs and a maximum rounded-versus-float difference of0.5 DN on that valid input. Whole and cropped outputs must be bitwise consistent for both policies, so moving the transform centre to the crop cannot pass. This is a pre-merge control and is not an output-error bound through nonlinear fusion.

The exact test entry is `merge_cmd::gatefloor::native_direct_planes_independent_tests::independent_direct_planes_controls`. Root supplies fresh `STREHL_GREEN_PROBE_OUTPUT` directories and separate processes for `STREHL_DIRECT_PLANES=off|rounded|float`; no in-process environment mutation can reset the OnceLock. Reuse the existing green controls to record actual seeded/WB/full/crop beta bits, tiny empty-band behavior, the retained NaN metadata fault and whole/crop TIFF bytes. Root compares matching off/rounded receipts and decoded pixel payloads. Float must be treated as a separate policy, with beta measured under that same policy; it need not match rounded. Plane fallback and no-warp controls must remain on their original path. The old scalar baseline and explicit old remosaic helper remain independent of the new environment arm.

A final TIFF equality alone does not establish equality of every pre-writer collapsed float, because quantization can hide small differences. The current reused green renderer emits complete TIFF bytes; any claim of collapsed f32 equality additionally needs an actual pre-writer value capture from the existing merge. This gap was reported to root before the first build. Current direct sink plane comparisons are explicit bit comparisons, not TIFF-derived inferences.

## Frozen interpretation and limits

No control has been run by this verifier. Required cases have explicit assertion witnesses; a failing control is retained and diagnosed rather than excluded or weakened. Existing source edits are two small test-only observer calls plus callable visibility, not a replacement fixture or renderer. A passed generated control establishes operator equivalence on these cases; it is not sensor calibration, precision benefit or native throughput.

The fixed actual-output population and quality bars are in design.md: fresh off/rounded/float on eleven saved M194b nine-frame bundles, flat first, at most33 primary TIFFs. The flat variance comparison retains temporal repeats and fidelity companions; variance alone can reward a biased or blurred result. Plane fidelity retains both optical and ideal targets and fixed complex waves, and colour retains genuine chroma and local extremes. No output-guided threshold, target, window or population change is authorized. The inherited S4/S8 plane discrepancy sets an engineering ranking floor, not a rigorous propagated uncertainty bound. Rounded speed requires a separately bounded native comparison with complete output identity; the tiny controls cannot establish it.
