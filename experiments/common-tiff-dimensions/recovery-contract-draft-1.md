## Independent controls before admission

The independent author fixes a finite metadata control table in recovery-spec.md
before any control execution. It must exercise the actual production predicate
and admission boundaries, including:

- ordinary and valid local verbatim references to one actual file;
- distinct existing paths with identical content;
- changed extent, digest and invalid extent type;
- unsupported device/UNC and malformed verbatim components;
- restored positives and unchanged original legacy artifacts;
- failed-parent versus successful-child provenance, wrong producer identity,
  incomplete transport and changed fixed-index association.

Name the rejecting input and require evidence that the relevant branch was
visited. Reusing existing predicate code does not license accepting hash-only
identity or weakening the failed-stage boundary. Control construction and
execution are distinct from the 24 application cases and 135 numerical controls.

The exact table, source hashes, command, environment, output paths and retention
bounds must be finalized in a committed release. No automatic retry follows a
refusal. These source-phase requirements are not a claim that controls have run.
