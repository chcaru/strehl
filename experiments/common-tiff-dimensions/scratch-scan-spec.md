## Bounded publication and limitations

The fixed fixture has only scratch/retained roots and two files each,plus a
separate missing-root spelling. Each write is at most11 bytes; no recursive
cleanup or deletion. Only the own named11-byte victim is unlinked for the two
race cases. Recreating that exact file is recorded; no unrelated path is
moved, removed or rewritten. Target paths are always below the fresh output.

Each row<=2KiB;16 rows plus4KiB framing<=36KiB, final<=64KiB. Progress<=40KiB
and its one transient stage is atomically replaced; total writes/readbacks are
charged, not only surviving extents. Final result.json is raw-identical to
stdout. At most20 bounded publications plus fixture writes; enforce the1MiB
read/write caps before every content operation. Final source readback is
bounded and included. Source refs are strictly positive. Empty metadata is
not admitted as source. Result schema common-tiff-dimensions-scratch-scan-controls-v1;
status PASS_FIXED_SCRATCH_SCAN_CONTROLS only with16 passed rows, restored
module identities and complete output/outer success; otherwise REFUSED.

Passing controls commissions this narrow production code path. It does not
certify peak compiler storage, reconstruct build1's missing path spellings,
prove an arbitrary filesystem race safe, or authorize a build rerun. No
product, old fixture/control, numerical, RAW or external source is executed.
