# Independent decision: no immediate focus-bracket implementation

2026-10-27. **NO-GO for the next bounded photographic implementation, not rejection of learned continuous reconstruction as a family.** Reviewed the linked primary sources and retained Strehl results; no implementation source, model download, training, inference or RAW/image data was opened or run.

The paper does provide a materially different value path: coarse demosaicked RGB conditions the kernel, while final values come from original CFA samples. Equation1 permits signed cross-color weights and normalizes by their absolute sum. Equation2 conditions on offset, channel and the output-pixel latent, without an individual source identifier. The encoder accepts3N channels; training uses five translated views of one image with simulated read/shot noise. This is not an explicit injected-noise covariance or focus-bracket contract. [Primary paper, sections3.1-3.5](https://people.csail.mit.edu/cjbisc/burst/burst_paper.pdf).

**Independent inference:** coincident same-color samples receive equal kernel weights even if their focus differs. The latent could condition a learned spatial inverse, but the specified value path does not independently admit their different-depth contributions. Adding source/band-conditioned visibility would be a new model question, not a runtime switch. Nor does the signed absolute-sum normalization guarantee DC/color preservation or prohibit fabricated detail. These observations prevent calling this a ready focus-bracket consumer; they are not an impossibility proof for a redesigned network.

The [official project page](https://people.csail.mit.edu/cjbisc/burst/) was checked directly. Its Code link returns the project page; no usable official repository, implementation license or trained checkpoint was obtained. This is a concrete delivery gap, not a claim that no implementation exists anywhere. The supplementary link exceeded the browsing tool's size limit; it was not treated as inspected code or weights. A paper description does not supply an immediately reproducible299-source inference path.

The prior failures constrain adaptation rather than ban it. [Direct-plane precision](../../native-direct-planes/results.md) never removed source MHC. The [free-image deflation result](../joint-cfa-local-fit/constant-deflation/independent-receipt-audit.md) retained excess chroma despite lower residual; original-sample access alone was insufficient. The [local variance-cap proposal](../joint-cfa-local-fit/identifiability/operator-proposal.md) could suppress all detail corrections under its strict cap. None supplies this missing learned estimator, a calibrated noise gate or different-depth behavior.

**Action:** close this paper-to-immediate-experiment route now. Do not implement an approximate untrained substitute and call it the published method, subset299 into five frames, or silently merge five-frame outputs. Reconsider only with a licensed runnable artifact and a defined original-sample admission rule that faces the already retained flat, independently colored and same-channel near-fine/far-coarse witnesses. Those would still require complete photographs before any quality claim. No new test campaign is proposed under this allocation.
