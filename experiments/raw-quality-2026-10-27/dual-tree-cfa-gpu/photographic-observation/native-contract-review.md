# Independent native-RAW contract review

VERIFIED by source inspection, 2026-10-27. No job, RAW decode, image computation or frozen-source edit was performed. The ongoing photograph has not been reviewed here.

**The current candidate fuses CFA-domain samples that have already undergone per-source MHC reconstruction, Catmull-Rom interpolation and u16 re-quantization. It is not direct fusion of original CFA observations and does not fulfill the literal demosaic-once contract.** Keeping original files and source storage as u16, and performing the merge before final display development, are real but narrower properties.

## Actual sample path

1. [The full adapter](../../dual-tree-cfa/full-adapter.rs), `full_gather` at line82, clones one decoded `Frame`. At lines112 and119 it calls `warp_frame_in_place` and then `extract_planes`. The candidate signal receives `canonical.planes` from the same production path at lines624-641; all sixteen candidate noise draws use the explicit all-four-phase callback. The bound environment requires fullres gathering, direct planes off, CPU gathering, CA off and Malvar (`full-adapter.rs:355` onward).
2. [Alignment orchestration](../../../../crates/strehl-cli/src/align_cmd.rs), lines2176 and2480, routes this to `warp_frame_fullres_coordinates_impl`. Lines2678-2727 allocate a black-subtracted, white-balanced full-resolution mosaic and three full-resolution R/G/B planes. `demosaic_row` is actually called at line2719. [The demosaic implementation](../../../../crates/strehl-core/src/demosaic.rs), lines338 and413, resolves the frozen Malvar selection to MHC; missing channels use cross-colour stencils.
3. `align_cmd.rs:2763-2798` selects the site's reconstructed channel and Catmull-Rom samples it at the transformed native coordinate. For fractional placements, these samples generally include reconstructed values rather than only original same-colour sensels. `writeback_fullres_site`, lines2397-2447, divides out WB, restores black, rounds, clamps to the u16 container range and writes a new CFA-pattern buffer.
4. [Plane extraction](../../../../crates/strehl-cli/src/merge_cmd.rs), lines4862-4926, converts that buffer to the four compact f32 planes and applies `(sample - black).max(0)`. The dual-tree consumer then operates on these reconstructed, quantized, black-clipped inputs. The injected original sensor noise is transported through this same path; this does not turn the gathered values back into original measurements.
5. `full-adapter.rs:176-230` creates the final merged mosaic, reapplies WB/normalization and calls [the image writer](../../../../crates/strehl-cli/src/image_out.rs), `write_demosaiced_with_master` at line1398. That writer runs `demosaic_row` again for the linear and delivered exports (lines1423 and1452). Those exports independently evaluate the final demosaic; they do not remove the earlier per-source demosaicing.

The original corpus remains immutable. The implementation streams one source and uses f32 arithmetic without an aligned-frame volume. It also materializes full RGB reconstruction scratch for each consumed source/probe. Its same-colour output labels do not imply independent original-colour evidence: MHC dependencies persist after remosaicing. The comment at `align_cmd.rs:2341-2343` saying demosaic mixing is "undone" by writing sites to their own colour is mathematically misleading. No comment or implementation was changed during this frozen run.

## Existing routes do not erase this distinction

[Native direct planes](../../../native-direct-planes/implementation.rs), lines29-42 and78-112, changes the destination sink of the same full-resolution reconstruction. Rounded mode reproduces existing quantization; float mode omits intermediate integer rounding but retains the MHC source reconstruction, container clamp and black clamp. It is not an original-CFA sampler. Its [prior results](../../../native-direct-planes/results.md) establish rounded parity and a rejected fixed precision trial, not demosaic-once reconstruction.

The distinct [direct-CFA sampler](../../../../crates/strehl-cli/src/direct-cfa-gather.rs), lines54-133, reads immutable original u16 sensels through `ActiveCfa`, combining the two measured green lattices and same-colour R/B cubic interpolation. That optional feature is absent from the frozen GPU build's declared features and is not this run's path. Its [recorded October26 result](../../../raw-quality-2026-10-26/results.md) rejected the fixed sampler for neutral-detail losses; the unchanged-green residual follow-on did not repair them. These negatives do not reject every original-CFA reconstruction, but neither are they grounds to describe the current MHC-remosaic route as fulfilling the original-CFA contract.
