## Producing path

Count-aware Haar uses original photosite counts for unequal children, the corresponding orthogonal inverse, squared variance weights, and exact Boolean dependency support. Equal-count children retain the old arithmetic. Odd carries retain their count, so a subsequent unequal merge no longer treats a one-cell support as a two-cell support. The new independent reference derives counts from clipped original coordinate bins; it does not read the producer's count arrays.

The first source pass aggregates Q and R over the same admitted coefficients, across all sources, physical phases, and orientations. One positive scalar R/Q per AC level is then shared by every source and color. LL is unchanged; total-metric overrides bypass balance; empty support is omitted and inconsistent/nonfinite support refuses. The final global scale is computed from the balanced per-level maxima and unchanged LL maximum. This preserves within-level relative precision but deliberately changes relative precision across levels. It is neither a likelihood proof nor a variance guarantee for data-dependent weights.

Original u16 cache loaders, physical phases, injected noise bits, fixed geometry, paired original-cell measurement, coefficient-space nuisance projection, and true final residual evaluation are retained. The four-step normal-CG recurrence has no restart or new prior. Checkpoints receive a cloned correction field and copied history entry; publishing cannot directly mutate CG scratch. Checkpoint failure raises outside the numerical-refusal catch. Finite intermediate fields may be shown while their numerical status remains unaccepted.

The worker binds all 299 original caches before and after, validates headers and metadata against the frozen export, and consumes them one source at a time. It does not rehash original ARW bytes; original byte identity is inherited from the verified export and current ARW metadata is checked. Intermediate delivery restores actual constants, integrates reference cells, and uses the frozen native RGB developer. It performs no per-source RGB reconstruction, MHC, remosaic, or exposure retuning. The final checkpoint latent hash must equal the solver's returned physical field.

## Presentation and release boundaries

Views require each checkpoint's own native master and signed camera master using filesystem identity, exact delivered crop `(68,46,6896,4596)`, fixed development and ICC, complete RGB16 pixel readback, and ten unchanged native 384-pixel crop origins. Full JPEGs retain native dimensions and ICC; their compression is lossy. Overview resizing is explicitly for orientation. Native and Helicon B4/B8 references retain their different gauges and existing mapped crops; no new registration is inferred.

The exporter explicitly does not certify complete-job status, source consumption, or numerical convergence. The worker and root completion wrapper own those checks. The wrapper requires all three checkpoints, exact four-step completion, source preservation, complete bound artifacts, and false quality/admission flags. Earlier stopping remains incomplete rather than duplicating an image to fill the schedule. Bounds are 300 seconds for controls and 1500 seconds for the single photographic pilot, with no automatic extension.
