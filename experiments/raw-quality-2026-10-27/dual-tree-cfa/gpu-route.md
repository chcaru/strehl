## Concrete streaming protocol

1. A persistent CUDA child receives one `start`: bank/constants/source hashes, exact crop/phase order/level geometry, mirror convention, input count, injected-noise identity and fixed gate/floor definition. Return frozen code/runtime/device identity. No source paths or RAW loader belong in this child.
2. Rust retains one original u16 frame and produces the exact existing cropped gathered four-plane field. Send `source(index, shape, payload_hash)` and then each of the16 already specified probe fields in order. Child acknowledgements prevent a source/probe queue. Do not change seeds, antithetic pairing, quantization or the original-variance model merely to make transfer cheaper.
3. CUDA independently performs the fixed real FIR row/column bank, packing, smoothing, floor, shared nonnegative weights and coefficient accumulation. Real/imaginary arrays stay f32; no f16, autocast, TF32 or source RGB. Process one probe at a time; retain only needed reference coefficients/floor accumulators. Release temporary levels/phases rather than all-source fields. The true signal may be transformed again after the floor to reduce peak residency.
4. Keep candidate numerator/denominator and spatial-mean fallback on device across sources. `finish` validates all299ordinals, synthesizes the four planes, returns those final f32 fields once and records before-hull/null diagnostics. Rust applies the same actual hull/writer and retains complete masters. Do not send2GB transformed banks back and forth per source.

The first wire format can be f32 for simplicity: about126.8MB per complete gathered source/probe, roughly644GB total for17fields×299sources. That transfer is part of cost, not free. A small exact optimization is u16 wire storage for these already rounded black-subtracted gathered DN values only when every value is proved integral and in0..65535. CUDA's conversion back to f32 is exact for that range. This halves wire traffic; it is not a claim that these gathered values are original camera codes. No lossy packing or below-black policy change is allowed. Keep the f32 format if this eligibility check fails.
