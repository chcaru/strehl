# Limited primary-source context

Kwon, Choi, Jang and Pang's2017 paper, *All-in-focus imaging using average
filter-based relative focus measure*, describes pairwise relative focus using
correlation after average filtering. This establishes prior art for relational
focus cues; it is not the elliptical-Gaussian held-out model implemented here.
The publisher abstract was available through search, while a direct page open
returned403. No paper source code was inspected and no novelty claim is made.

[Publisher abstract](https://www.sciencedirect.com/science/article/abs/pii/S1051200416301555)
and [author institution record](https://sejong.elsevierpure.com/en/publications/all-in-focus-imaging-using-average-filter-based-relative-focus-me/).

Xu et al.'s2020 *Towards Reducing Severe Defocus Spread Effects for Multi-Focus
Image Fusion via an Optimization Based Strategy* optimizes agreement of fused
regions with estimated sharp source regions. Its abstract does not resolve
our source-ownership ambiguity; it is not evidence for this implementation.
[Primary manuscript record](https://arxiv.org/abs/2012.14678).
