**Try moving the location that supplies source evidence, not inventing another
focus score.** An off-core fan should borrow evidence only from an automatically
tracked core to which its observed support belongs. A separate real ridge keeps
its own source evidence. The hypothesis is that this relationship is sometimes
observable as a component lineage; topology alone is not proof of ownership.

   contrast field, retaining local maxima and their merge saddles across all

   candidate, not a sharpness or photon-mass claim.
2. Track markers and their saddle-bounded branches through the complete source
   sequence using mutual spatial correspondence in the existing reference
   coordinates. Retain only unambiguous one-to-one continuations. A split,
   merger, competing persistent marker or missing correspondence makes the
   disputed support unknown. Do not bridge it by nearest-core propagation.
   Source-order reversal must give the same lineage with reversed indices.
3. For each retained lineage, derive one source-weight vector from the actual
   finest-band energy/floor **inside its persistent core**, using the existing
   SoftPower/noise-average rule. Require agreement of two fixed, disjoint core
   subsets before transporting those weights. Do not rank component radius,

   it does not assume the old focus score is now correct.
4. Transport that one weight vector only to the observed, unambiguous branch
   footprint. Other persistent branches retain their own evidence. At unresolved
   crossings, use zero activation and preserve the baseline exactly. Feed these
   memberships, shared by all four planes, into the existing whole-AC `Replay`,

   source index enters the algorithm.

Both outcomes close this exact intervention; no watershed-radius, threshold or
nearest-marker rescue. The core focus rule can also choose the wrong source,
which the same delivered-image truth guard must expose.
