# Green output work omission: implementation notes

2026-09-09. Author implementation only; compilation, executable controls, native output equality and performance remain UNVERIFIED. Root executes and the separate verifier re-chooses controls. No source calibration, data acquisition or architectural change is introduced.

`strehl_core::demosaic::demosaic_green_row` returns one width of green samples using the same `use_directional` selection as the RGB entry. Green CFA sites return the original sample. Red/blue sites call the existing `green_directional` or `conv(..., &F_G)` unchanged; the complete source mosaic is still required.

`align_cmd::warp_frame_in_place_fullres` now calls a private const-generic output specialization with `GREEN_ONLY=false`. Its original geometry check, complete black-subtracted/WB-balanced mosaic, three-channel demosaic expressions, guarded CA resolution, f64 site transforms, resampling, f32 inverse gain/pedestal, coverage and u16 quantization stay shared. The `true` specialization allocates only the green reconstructed output plane, calls the new green row, and skips the R/B destination sites. Its source mosaic still contains ALL CFA channels. The ordinary actual-image dispatch always uses false. Skipped destination values remain the synthetic input; only the probe's existing G1/G2 extraction consumes the result.

`warp_probe_greens_in_place` exposes no partial coverage fraction and preserves the original four-site plane-gather fallback. `warp_probe_greens_in_place_fullres` exposes the direct candidate for independent comparison. The shared helper internally normalizes any returned coverage by the number of visited sites; the green wrappers discard it. All source demosaic work finishes before any destination update. CA guard/errors are resolved in the same location. Scratch buffers are overwritten for each visited site and remain caller-owned.

`STREHL_PROBE_GATHER=rgb` runs the original ordinary warp. `green` and unset select the candidate in this held binary; that candidate default is not accepted until the required controls and native timing succeed. Unknown/non-Unicode values return an error before cloning or filling a probe. The parsed choice is immutable within a process, matching existing comparison switches. No unsafe environment mutation is needed: root runs distinct control processes. The existing scalar/parallel RNG choice and every generated source sample remain untouched.

Author source review accounted for the deletions: one obsolete only-dispatch doc sentence was corrected; the original RGB demosaic loop was nested under the false branch without arithmetic edits; two unconditional reconstructed-plane allocations became conditional; the original four-site denominator became visited-site normalization; and the probe's original warp call became the explicit comparison dispatch. No scientific result or speedup is claimed by this inspection. Exact green/beta/full-TIFF comparisons must have live fractional, red/blue-source, border/layout, WB, directional and plane-fallback cases, as specified in the charter.

Root additionally authorized test-only fixture/render wrappers inside the existing m194c independent module plus a sibling include for the separate verifier's `independent-tests.rs`. These expose its existing functions without changing production execution. The test source is owned by the verifier.
