2026-09-25. **A pretrained deterministic candidate exists; a fully verified ready comparator is not yet established.** GMFF's independent StackMFF V4 first stage is the strongest release lead from this bounded check. No implementation was opened, no repository/checkpoint was downloaded, and nothing was installed, trained or executed.

Read prior `B-algorithms-sota.md` §3.5–3.6 and the FocusDeep feasibility closure. Root ran `prior_art.py StackMFF learned focus regression` before this check. The deterministic/diffusion distinction is already known; available pretrained releases are the new readiness fact.

The GMFF README documents a standalone `inference_stage1.py` invocation with `stackmffv4.pth`, numerically named image files and no training step. Diffusion is a separate stage with separate weights; it is unnecessary for that invocation. The standalone [V4 repository](https://github.com/Xinzhe99/StackMFF-V4) delegates to GMFF/V3 rather than supplying another independent pretrained package. V2/V3 also document pretrained single-stack prediction. These are conventional image-stack entry points, not documented CFA-native APIs.

**Published inference limits, not measured here:** V4's paper describes focus-map generation, order invariance and attention across stack layers. Training images were resized to 384×384; its FLOP comparison uses two 256×256 images. The reported 0.12-second Mobile Depth average is not a 488-frame, 33-MP timing. No explicit maximum stack count, tested 488-frame case, full-resolution memory bound or streaming/tiling API was established from the inspected README/paper. Therefore arbitrary-length practical inference and source-map export remain **UNVERIFIED**, even though variable-stack fusion is the stated purpose. [Primary paper, §III-B and §IV-A/B](https://arxiv.org/html/2512.21495v1).

**Decision:** this is a more concrete lead than the closed FocusDeep release, because both documented deterministic inference and an actual small checkpoint are present. A root decision on the exact MIT declaration scope, followed by a narrowly scoped inference/API inspection, could resolve readiness. This check neither authorizes integration nor claims model quality on the user's macro stacks.
