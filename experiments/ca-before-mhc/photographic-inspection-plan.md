# Whole-chip inspection, before candidate images

This is one complete photographic comparison, conditional on the separately
declared colour qualification and the one-source resource checkpoint. Current
and Before use every one of the same 299 originals, the same fixed map, crop,
merge/development and tone. No local placement correction is active in either.
The common crop is quad `[141,97,3234,2150]`, i.e. output 6468x4300, native
origin `(282,194)` in the anchor gauge. It is 16 native pixels inside each side
of the old common output. Baseline must be newly rendered with this consumer
context; a crop of an older final image is not substituted for it.

First inspect both complete fields, then fixed native views. Native rectangles
below are output pixel coordinates and were chosen from the existing whole-chip
baseline, before a candidate exists:

| Purpose | x | y | width | height |
| --- | ---: | ---: | ---: | ---: |
| Prior rail/crossing target | 1082 | 942 | 384 | 384 |
| Upper coloured motifs | 1020 | 180 | 512 | 512 |
| Central fine stipple and boundaries | 2960 | 1290 | 512 | 512 |
| Lower-left repeated array | 550 | 2780 | 512 | 512 |
| Lower-right coloured structures | 4650 | 3000 | 512 | 512 |
| Low-texture surface and scratches | 4840 | 1240 | 512 | 512 |

The last region is a visual smoothing/artifact control, not a calibrated flat
field or a temporal-noise estimate. No gradient-energy quality score is used.
Inspect separated lines, crossings, fine motif openings, coloured boundaries,
ringing, periodic colour stipple, scratch continuity and broad tonal/color
changes. Lower visible chroma alone is insufficient: disappearing real colour
or merged line separations defeat a gain claim. Apparent extra detail must be
distinguished from false periodic contrast and supported by original-source
evidence if that distinction is unresolved.

An independent reviewer inspects the complete images and chooses an additional
defensible region, rather than being restricted to the author's selection.
Root also inspects the complete pair. No default change follows automatically
from this one image. If a useful photographic gain is found, show the owner
both full-stack images and links to both full-resolution masters, with the
scope and any remaining defects plainly stated. Never present only a crop as
the improvement.
