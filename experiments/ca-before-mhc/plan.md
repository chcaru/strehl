# Fixed CA ordering counterfactual

UNVERIFIED, default off. This tests whether MHC mixes geometrically displaced
colours before the existing per-colour pull can correct them. It is not a new
optical calibration, a fan-removal claim, or a replacement for failed native
inverse/phase-packed experiments. The shipped radial profile stays frozen.

For native green-coordinate site x, Before interpolates original same-colour
photosites at C_c(x), in f32 black-subtracted/WB units, then applies the existing
MHC and gathers only the common pull T. C_c is about the original quad centre;
native coordinates are twice quad coordinates. G sites copy the original sample
when their C is identity. Originals stay u16. No intermediate code rounding or
clamp occurs; the existing final rounded-u16 consumer is unchanged.

Current is the existing MHC then C_c composed with T. StagedAfter applies C to
the full-native MHC RGB lattice and then T. It controls an additional sampling
stage but is NOT blur-equivalent to a same-colour two-native-pixel lattice.
Independent continuous neutral and genuine-colour truth is therefore required.
All-zero CA bypasses both new paths literally. Same-colour interpolation,
MHC and final interpolation propagate unsupported input as invalid; any invalid
sample in the displayed crop refuses the run. No black-filled support is scored.

One source CFA/RGB scratch buffer is resident; no aligned-frame volume. Host f64
coordinate plans are streamed in strips; f32 strict GPU image arithmetic uses
the existing MHC/Catmull expressions. Actual and injected gate-floor probes use
the identical selected route. Merge, noise injection, bands, weights, canonical
chunking and final development remain unchanged.

The initial bounded implementation uploads three plans per native site in
32-row strips, including unused Before colour plans. This is deliberately
simple, not a speed claim. Root must measure a one-source cost before committing
to a 299-frame replay. Default-off source shader and numerical path are retained;
the opt-in shader is generated by replacing only the MHC source accessor and
adding an invalid-support check to the existing final gather, plus a new prepass.

`STREHL_CA_BEFORE_MHC=off|before|staged-after` is feature-contained in the GPU
gather route and defaults off. Nonzero modes require GPU, rounded direct planes,
Malvar, Catmull and no local placement. Test-only scoped explicit CA pulls permit
small virtual off-centre sensor crops with shipped radial slopes and derived
intercepts; these are operator plants, not gear calibration.

Root owns fresh builds and runs. Independent controls own flat/noise first,
neutral/colour detail, extra-stage comparison, sign/phase, support refusal,
zero-CA equality and original immutability. If admitted, root renders complete
chip baseline/candidate at the same fixed crop/map/tone, with all additional
support held before images are judged. No author execution.
