# Application recordings

These GIFs show the real Strehl Windows application working with the owner's
299-frame Sony ARW insect bracket. They were captured on 2026-10-19 using the
Windows computer-use screenshot interface, then encoded with FFmpeg. They are
not mockups or generated images. The private RAW bracket is not distributed.

- `stacking.gif`: 63 frames, sampled from a fresh render's 125 captured frames;
  1440 x 986, four frames per second. Time-compressed, including alignment,
  progressive band accumulation, reconstruction, and the completed photograph.
- `timeline-scrubbing.gif`: 54 captured frames; 1440 x 986, eight frames per
  second. Three real timeline drags change the source comparison and admission
  regions while the finished photograph remains visible.

The recording build precedes the release version metadata change. Its executable
SHA-256 was `5087067bd7d1252d2f9b72949b0c4d03d6ebe36d023d9e797dd6d2f00eb47a05`.
The screenshots are sampled and the GIFs are quantized; neither is evidence of
rendering speed, interaction latency, native-pixel sharpness, or color accuracy.
