## 1. The identifiability result

### 1.1 General statement

**INFERRED BY READING.** Let `W` be a class of latent worlds, let `Phi(W)` be the rendered observation available to a statistic, and let `L(W)` be the correct quality ranking. If there are worlds `w_d` and `w_i` such that

```text
Phi(w_d) = Phi(w_i), but L(w_d) != L(w_i),
```

then no deterministic statistic `f(Phi(W))` can return the correct ranking in both worlds. The input to `f` is identical, so its output is identical, while the required output differs. This is an identifiability failure, not a statement about optimization quality or sample size.

A prior can change posterior plausibility. For example, a prior that strongly favours spatially uncorrelated noise over impulse-like scene detail can favour the denoising explanation. That does not distinguish the two observations without assumptions: the prior is the additional identifying assumption. It narrows the claim to the population on which that prior is validated.

### 1.2 Executable finite witness

**VERIFIED BY RUNNING.** `experiments/M168-identifiability/finite_witness.py` constructs

```text
A = [0, 0, 1, 0, 0]
```

and a nonnegative, row-stochastic tridiagonal smoother `G`. It then constructs:

- degradation world: `A` is faithful and `B = G @ A` is blurred, so prefer `A`;
- improvement world: `B` is faithful and `A = B + (A-B)` contains removable artifact, so prefer `B`.

The code compares both values and bytes, rather than asserting the equivalence in prose.

### 1.3 Exact scope

**INFERRED BY READING.** The witness proves that no output-only statistic can **guarantee** the intended ranking uniformly over an unrestricted world class containing both constructions. It does not prove:

- that every individual output pair is ambiguous;
- that a validated natural-image prior cannot rank likely worlds probabilistically;
- that restricted known-noise or known-renderer families are untestable;
- that controlled featureless-target noise claims are impossible; or
- that external reference information must have one specific implementation.

The single-image “detail versus sharpening” problem and the two-output “detail versus removed noise” problem share the abstract non-injective-observation theorem when each admits an identical-observation/opposite-label construction. They are not the same concrete experiment. D8 failed through common-filter invariance, while the band-power candidate failed an empirical flat null; those deaths are not retroactively proofs of this theorem.

## 4. Why M1 is current but not mathematically unique

### 4.1 Algebra

**INFERRED BY READING.** In one scalar or Fourier cell, let

```text
R = H_R S + eta
Y_X = H_X S + epsilon_X
P_R = |H_R|^2 P_S
C_XR = H_X H_R* P_S
T_X = |C_XR| / P_R = |H_X / H_R|.
```

For candidate `C` and comparator `B`,

```text
q = [sqrt(P_NC)/T_C] / [sqrt(P_NB)/T_B]
  = sqrt(P_NC/P_NB) * |H_B/H_C|.
```

Both the common reference power and common reference transfer cancel. This is a statement about the comparative ratio under the linear, nonzero-transfer model. It is not an assertion that reference power can be zero or that a same-resolution reference supplies absolute scene truth.

### 4.2 Executable cancellation witness

**VERIFIED BY RUNNING.** `experiments/M168-identifiability/reference_cancellation.py` changes `H_R` enough to move `P_R` from `0.48` to `2.43`, while holding the candidate/comparator physical terms fixed:

```text
H_R=0.9 P_R=2.430000 T_C=0.888889 T_B=0.444444 q=0.500000
CANCELLED_FORM=sqrt(P_NC/P_NB)*abs(H_B/H_C); no P_S, P_R, or H_R
PASS: q=0.500000 for both reference transfers
```

Thus the `0.500000` values quoted in Amendment 6 are correct.

### 4.3 What this does and does not replace

**INFERRED BY READING.** A same-resolution reference can normalize **relative** transfer only if it is independent, nonzero and sufficiently powered on the admitted cells. It does not reveal shared optical zeros, absolute truth, aliasing outside the sampled passband, correlated source pixels, or repeatable detector structure. Those require additional controls.

M164 also shows that `Q_EIN` alone prefers the blur-plus-denoise arm at `0.583120x` while transfer falls to `0.571748x`. A separate detail/transfer admission condition is therefore real. M1 is the current concrete implementation and capture plan for that condition. The algebra does not prove that only M1 can ever implement it.

The archive-specific follow-up in `docs/research/M168-cheap-reference-feasibility.md` found no physically usable same-resolution route in the supplied archive. That practical absence does not restore mathematical uniqueness.
